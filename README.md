# Strix Table Prototype

Strix 的阶段 A 灰盒舞台：Vite + React + TypeScript + React Three Fiber。

## 运行

```bash
npm install
npm run dev
```

开发地址：`http://localhost:4174/`。

## 当前范围

- 全屏 3D 桌面与 3×3 棋盘
- 程序化灰盒手牌和牌堆
- `board / hand / overview` 三种受控镜头
- 可悬停、可选择的九个棋盘格
- Game Core / Store / Scene / HUD 分层骨架
- 空间查询的最小单元测试

规则、拖拽、结算与正式资产刻意留在后续阶段。
