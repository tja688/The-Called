单机CCG卡牌对战游戏 play test 原型 ：the called

一句话简介：在九宫格中轮流放置卡牌，抢占场地，覆盖吞下对面的卡牌，当场地被铺满时进入终局之战，在即死的风险下跟敌人展开惊心动魄的博弈

游戏处于play test 原型验证阶段，画面风格为3d极简几何

几个核心设计：

1、放置满九宫格场地后进入结算流程（即终局之战），对于双方而言，在属于自己的回合开始时，自己处于领先则会获胜。

2、敌方卡牌是无限的，代价是每轮敌方的意图可知（下张出什么牌，但不清楚出在哪），玩家的牌组构建是有限的。因此必然会出现铺满场地的情况。

3、若遇到极限情况：即场地满且双方分数均等，并且敌方无更大的点数卡牌在手，则场地上所占空间更大的一方获胜。

4、双方点数更大的手牌可以覆盖掉场地中点数更小的牌，同点数不可覆盖，无论因何情况导致场地中卡牌点数减为0，则直接破坏卡牌移除出场地。

5、各类卡牌效果若无明确说明，则在放下时触发，之后再结算覆盖点数的削减。
