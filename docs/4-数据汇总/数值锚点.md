# 数值锚点

本原型用这张表。调参先改这里，再改卡面。

## 局外

| 项 | 值 |
| :-- | :-- |
| 血条上限 / 初始 | 30 / 30 |
| 牌组张数 | 无上限，至少 1 张。开局 10 张 |
| 手牌上限 | 10 |
| 开战抽牌 | 化身 + 4 |
| 之后每回合抽 | 1 |
| 化身基础点数 | 10 |
| 普通 / 精英战败扣血 | 10 |
| 战后化身伤口 | `max(0, 10 - 终局当前点数)` |
| 卡盒容量 | 无上限 |
| 地图效果 | 阴影地，角落 +1 |

## 费用

| 项 | 值 |
| :-- | :-- |
| 每张未封印己方占场 | +1 费用上限 |
| 化身入场 | 立刻 +1 当前费用 |
| 普通占场入场 | 只 +1 上限 |
| 初始牌费用带 | 0~2 |
| 奖励牌费用带 | 0~3 |

## 节奏

| 场 | 敌方开局最终点数（含阴影地、驻场） | 期望回合 | 期望战后扣血 |
| :-- | :-- | :-- | :-- |
| 余桩 | 17 | 2~4 | 0~3 |
| 剥手 | 17 | 3~5 | 2~6 |
| 守门 | 22 | 4~6 | 3~8 |

开战回合算第 1 回合。领先检查最早出现在第 2 回合开始，因此最快也是「开战落地 → 压过 → 撑一轮压迫 → 下回合赢」，共经历 1 次压迫。

## 点数带

| 类型 | 基础点数 |
| :-- | :-- |
| 初始小占场 | 2~4 |
| 初始大占场 | 6 |
| 奖励大占场 | 5~8 |
| 第一、二场敌方 | 4~7 |
| 守门核心 | 7，加上驻场和角落后总盘约 22 |
