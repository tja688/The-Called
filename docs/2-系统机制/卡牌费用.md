# 卡牌费用

占场产水晶。法术花钱。敌方不产费用。

## 水晶

场上每张未被封印的己方占场（含化身）提供 1 点费用上限。

| 时机 | 当前费用 | 费用上限 |
| :-- | :-- | :-- |
| 战斗开始，化身未入场 | 0 | 0 |
| 化身入场 | +1 | +1 |
| 普通占场入场 | 不变 | +1 |
| 己方占场离场或被封印 | 当前费用与上限各 -1，当前费用不低于 0 | |
| 玩家回合开始（开战回合除外） | 回满到当前上限 | 不变 |

普通占场当回合只把上限撑高，下回合才能用这点新水晶。化身入场的那一点立刻能花。

## 打出时

- 费用不足不能打。
- 先扣当前费用，再入场或结算法术。
- 0 费占场不扣费用。

## 本原型没有的

点数费用、格子费用、指定产费格。见 [[第四版裁定]]。
