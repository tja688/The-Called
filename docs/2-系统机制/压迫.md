# 压迫

敌方不抽牌、不打牌、没有费用。它们开局就在格子上。玩家结束回合之后，场上敌方占场按格号结算一次压迫。

## 顺序

1. 玩家结束出牌阶段。
2. 按格 1 → 9，对每张仍在场、未被封印的敌方占场结算它的压迫。
3. 一张牌的压迫结算中若有其他牌离场，后面的格号看到的是已经变化后的战场。
4. 若此阶段化身离场，立刻按 [[领先与胜负]] 判负，不再结算后面的压迫。
5. 全部结算完，进入玩家下一回合开始。

没有压迫栏的敌方占场跳过。

## 驱离

词条。把化身移出战场，视为化身被移除。

## 驻场和压迫

驻场在整场战斗中只要还在就生效，包括玩家出牌期间。压迫只在压迫阶段生效一次。

一张敌方占场可以同时有驻场和压迫。
