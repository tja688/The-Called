# 事件

随机事件由「一段情境描述 + 2\~3 个选项」组成，玩家必须选择一项才能继续。同一局内每个事件只会遇到一次。出现条件需全部满足，该事件才会进入抽取池；条件不满足的选项置灰不可选。

作为[[地图节点]]出现。名称、选项名、情境与旁白见 [[虚构配置表]]。

出现概率档位：**高 65%、中 30%、低 5%**（调整档位权重只需改动本行）。

## 事件池

三层共用一个事件池，每个事件在「出现条件」中标注可出现的层数——可以是单层专属，也可以是三层通用；抽取时按当前层过滤。
