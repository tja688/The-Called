# 血条

决定这趟还能不能走下去。归零则失败。开战上限 30，当前 30。

## 扣

| 来源 | 数值 |
| :-- | :-- |
| 战斗胜利且化身仍在场 | `max(0, 10 - 化身终局当前点数)` |
| 余桩 / 剥手失败（化身离场或无牌可出） | 10 |
| 守门失败 | 不扣，直接整趟失败 |
| 事件选项 | 见该事件 |

胜利时化身点数高于 10，不回血。

## 回

本原型只有事件「包扎」+8。不超过上限。

## 意图

三场里化身会被削。护住化身，战后少扣；拿化身去盖高点或硬抗压迫，用血换节奏。30 点够打完，也够在余桩或剥手输一次再爬起来。守门不能靠血硬抗离场。
