# 词条

卡面上加粗。悬停显示本页解释。

## 时机

| 名称 | 效果 |
| :-- | :-- |
| **入场** | 被打出或被效果生成到战场时触发一次。被移动不触发。本原型无移动。 |
| **驻场** | 本卡在场且未被封印时持续生效。离场或被封印立刻失效。 |
| **被移除时** | 从战场离开时触发。被覆盖、被效果移除都算。 |
| **压迫** | 玩家结束回合后，按格号结算一次。见 [[压迫]]。 |

## 空间

| 名称 | 效果 |
| :-- | :-- |
| **相邻** | 正交相邻。不含斜向。 |
| **角落格** | 格1、格3、格7、格9 |

## 状态

| 名称 | 效果 |
| :-- | :-- |
| **封印** | 不提供点数，驻场不生效，敌方不结算压迫。玩家下个回合开始时解除。覆盖判定仍用当前点数。 |
| **驱离** | 将化身移出战场，视为化身被移除。 |

## 本原型不用

信仰、献祭、返魂、保护、解析标记、锁定、污染格、额外出牌、精神负荷。下一版若加回来，另开条目。
