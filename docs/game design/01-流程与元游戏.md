# 流程与元游戏

从一句话玩法到大地图、关卡与回合的完整流程链。胜负以本章 [[#玩法]] 为准。点数定义见 [[02-战场与对局规则#点数]]；卡牌区域见 [[03-卡牌与对局区域]]。

## 玩法

《TheCall》（暂定）是一款在 3×3 棋盘上展开的非对称卡牌博弈游戏。玩家洞察预判怪物的出牌意图并构筑对策，通过占位与点数攻防取胜。

本节是胜负的唯一准则。回合流程只在对应时机调用这里的判定。

**总原则**：任何结算都先比双方总点数，高者胜。总点数的优先级永远高于占格。只有下文写明的平点场合才比较实际占格（该方在九宫格上的卡牌张数），占格多者胜。

**满格判定**
九宫格被卡牌填满后，对局继续。此后每一方在**自己的回合开始**、且该回合开始效果已经结算完时，只看**自己的总点数是否大于对方**：

- 大于：该方立即胜利
- 不大于，包括双方总点数相同：本回合照常进行，对局继续

满格不平点，也不用占格裁决。

**资源结算**
**无可使用卡牌**指牌组已经抽尽，并且手牌里也没有牌。手里还有牌，或牌组还能抽出牌，都不算无可使用卡牌。

只在**玩家回合开始**、回合开始效果已经结算完、且玩家无可使用卡牌时判定：

- 怪物总点数大于玩家：玩家失败
- 怪物总点数小于玩家：玩家胜利
- 双方总点数相同，且怪物也无牌可出：按实际占格多者胜
- 双方总点数相同，但怪物仍能打出牌：此时不分胜负，对局继续

怪物无牌可出，指意图顺序中下一张要打的牌没有合法落点，场面因此陷入死局。没有可被它覆盖的牌，并且棋盘上也没有能打入的空格，才算没有合法落点。还有空格时，空格是合法落点，不算死局。法术卡随时可以打出，所以无牌可出只会发生在占场卡上。

同一次玩家回合开始若满格与资源结算都成立，按资源结算判定。

**特殊结算**
卡牌或怪物效果触发强制结算时，在该效果结算的当时立即判定：总点数高者胜；总点数相同则实际占格多者胜。不等到下一回合开始，也不改走满格判定。

## 循环

### 关卡内循环（最小循环）

单个关卡内的完整流程，边界为「进入关卡 → 返回大地图」。

| 顺序           | 规则层描述                                     |
| :----------- | :---------------------------------------- |
| 1. **关卡开始**  | 关卡开始，记录当前牌组初始状态                           |
| 2. **怪物生成**  | 确定本关卡出场的怪物，按照怪物数据在九宫格战场上摆放初始卡（摆放算作入场，结算其入场效果），然后结算关卡开始时的怪物技能（如干扰） |
| 3. **首回合开始** | 玩家先手，随后双方按回合流程进行，详见 [[#回合流程]]             |
| 4. **胜负结算**  | 回合流程中触发强制结算条件，详见 [[#强制结算]]                |
| 5. **卡组复原**  | 将牌组复原到初始状态                                |
| 6. **奖励环节**  | 战斗胜利后，获得可自行决定是否加入牌组的卡牌                    |
| 7. **战后去向**  | 胜利后返回大地图，可自由选择已解锁的关卡重复挑战；战败则不获得奖励，直接返回大地图 |

> 回合流程是其中的内层小循环，前一阶段未完成不得进入下一阶段，详见 [[#回合流程]]。

### 关卡推进

每个关卡对应一个怪物。对局胜利即为击败该怪物，并以此通过关卡、解锁后续关卡；一次通过可能解锁一个或多个关卡。通过后返回大地图，可自由挑战已解锁的关卡，同一关卡可以重复挑战，不需要连续打通。

## 大地图

玩家的据点界面。在大地图上可以挑战关卡、打开卡盒自由构筑牌组，或进入**商店**消费。

### 功能

- 关卡选择：从已解锁的关卡中自由选择，可重复挑战
- 卡盒构筑：可随时打开卡盒编辑牌组（见 [[04-构筑与经济#卡盒]]）
- 商店：用**金币**消费（见 [[04-构筑与经济#经济]]）

## 回合流程

回合流程固定为以下阶段，前一阶段未完成不得进入下一阶段：

| 顺序 | 规则层描述 |
| :-- | :-- |
| 1. **玩家回合开始** | 按 [[#回合开始的分层]] 结算玩家方回合开始时的效果，然后按 [[#玩法]] 做满格判定或资源结算 |
| 2. **确定意图** | 按**意图顺序**确定怪物本回合要打出的那张牌，并提前亮出。只亮牌名，不亮落点和效果目标（见 [[05-敌方与关卡#怪物意图]]） |
| 3. **玩家抽牌** | 从牌组抽 1 张卡牌作为手牌。手牌达到上限时不抽取，牌组为空时不抽取 |
| 4. **玩家行动** | 玩家每打出一张牌到格位，消耗一次出牌机会，打出的卡牌立即结算其效果。出牌机会用完时回合自动结束；玩家也可以随时主动结束回合。 |
| 5. **玩家回合结束** | 触发所有玩家方回合结束时的效果。若其中的效果触发特殊结算，按 [[#玩法]] 立即判定 |
| 6. **怪物回合开始** | 按 [[#回合开始的分层]] 结算怪物方回合开始时的效果，然后若九宫格已满，按 [[#玩法]] 的满格判定检查怪物是否胜利 |
| 7. **怪物行动** | 怪物执行本回合的意图，并立即结算其效果 |
| 8. **怪物回合结束** | 触发所有怪物方回合结束时的效果。若其中的效果触发特殊结算，按 [[#玩法]] 立即判定 |

同一时刻触发多个效果时的先后，见 [[#结算顺序]]。

回合流程会一直循环，直到一方胜利。

## 结算顺序

### 基本原则

- **逐步生效**：每一次点数增减、每一次卡牌移动都是独立的一步，按发生顺序逐一生效，不合并成一个最终值。例如覆盖扣点与污染格 -1 是先后两步，各自独立呈现。
- **归零即时**：每一步之后立刻检查，当前点数为 0 的卡牌立即被移除（见 [[03-卡牌与对局区域#卡牌与格位的关系]]）。
- **先结算完，再响应**：一个效果结算过程中被触发的能力不会打断它，而是进入队列；当前效果完整结算后，队列中的能力逐个结算。结算过程中新触发的能力追加到队尾。
- **结算前重查**：驻场类触发在结算前重新确认来源仍在九宫格上，否则作废；离场类触发按卡牌离场前的最后状态结算。
- **按次数触发**：一个事件包含多次发生（例如一次移除多张卡牌）时，响应它的能力按次数分别触发。

### 同时触发的先后

同一时刻触发的多个能力按以下顺序进入队列：

1. 怪物技能等全局来源
2. 九宫格上的卡牌，按格1 → 格9
3. 其他区域（手牌、牌组）中的卡牌

同一张卡牌的多条能力按卡面顺序。双方共用九宫格，因此不区分当前回合方。

### 入场效果

- 被打出的卡牌，其入场效果在打出时当场结算，先于其他被触发的能力。
- 生成、转化、复制出的卡牌，其入场效果进入队列。

### 回合开始的分层

回合开始时的效果分三层结算，每层内部按 [[#同时触发的先后]]：

1. 普通的回合开始效果
2. 状态维护：清除由本回合所属方施加的**封印**
3. **计时**倒数，并触发归零的计时效果

三层全部结算完之后，才进行满格判定或资源结算。

## 强制结算

触发后如何分胜负，全部以 [[#玩法]] 为准。这里只登记三类时机。

| 类型 | 触发规则 | 判定 |
| :-- | :-- | :-- |
| 格位强制结算 | 九宫格被卡牌填满时 | 之后每次回合开始，按满格判定 |
| 资源强制结算 | 玩家回合开始时，玩家无可使用卡牌（牌组已空且手牌已空） | 按资源结算 |
| 特殊强制结算 | 由卡牌、怪物效果触发 | 效果当时按特殊结算 |

总点数的定义见 [[02-战场与对局规则#点数]]。
