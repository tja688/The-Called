# 卡牌与对局区域

战斗中的卡牌本体，以及手牌、牌组（局内）、弃牌堆、消散区等区域。局外收藏与构筑见 [[04-构筑与经济]]；玩家/怪物卡表见 [[06-玩家卡牌与数值锚点]]、[[05-敌方与关卡#怪物方卡牌]]。

## 卡牌

游戏中战斗所需的基础单位，不同卡牌根据自身具体设计产生不同效果，一般拥有一个卡牌本身的效果，并可附加一个卡背。

### 卡牌存放

关卡内通过战斗获得的卡牌存放在**牌组**里，战斗结束后牌组将复原到初始状态。

### 卡牌与格位的关系

- 一个格位同时只容纳一张卡牌
- 卡牌一旦入场即属于打出它的一方，只会被特殊效果转移归属
- 卡牌的当前点数降为 0 时，该卡牌被移除出九宫格战场，进入弃牌堆；这是即时结算，每次结算后只要当前点数仍为 0 就会再次触发
- 因此 **保护** 会正常生效并消耗掉保护状态，但若此时卡牌点数仍为 0，会立即再次触发移除，卡牌仍会被移除
- 卡牌离场时，其对其他卡牌造成的**永久增减仍然保留**，其**驻场效果立即失效**
- 卡牌进入弃牌堆或消散区时重置为基础状态：清除所有点数增减与状态，卡背保留。卡牌在手牌、牌组、九宫格之间移动时保留自身状态

### 指代约定

卡面效果中的「己方」指该卡牌的所属方，「敌方」指另一方。

### 稀有度

卡牌稀有度分为白、蓝、金三档。

### 卡牌类型

无点数的是法术卡，有点数的是占场卡。

#### 占场卡

本身拥有点数，打出后会留在九宫格战场上的卡牌。

#### 法术卡

本身没有点数，打出后触发完效果直接进入弃牌堆的卡牌。法术卡随时可以打出；效果目标不存在时效果不生效，卡牌直接进入弃牌堆。

## 手牌

玩家在关卡内可以打出的卡牌。

### 初始手牌

关卡开始时，玩家从牌组随机抽取 4 张作为手牌。

### 手牌上限

最多持有 10 张，手牌满后无法再抽取卡牌。任何卡牌要加入已满的手牌时，改为进入弃牌堆。

### 打出规则

占场卡可以打出到九宫格空格位上，也可以打出到点数不大于它的对方卡牌所在的格位上进行**覆盖**，规则详见 [[02-战场与对局规则#覆盖]]。

法术卡本身没有点数，根据自身具体设计决定打出位置。

玩家每回合只有一次出牌机会（可依靠效果获得额外出牌机会）。出牌机会用完时回合自动结束。

## 牌组·局内

玩家拥有的、在关卡内可使用的卡牌集合。构筑限制与卡盒关系见 [[04-构筑与经济#牌组]]。

## 弃牌堆

存放所有被移除卡牌的区域，处于弃牌堆的卡牌只能被效果回收到手牌或牌组。双方各有自己的弃牌堆。

### 战斗结束

弃牌堆、消散区与牌组一起复原：所有卡牌回到牌组初始状态。

## 消散区

带**燃尽**的卡牌离场后进入的区域。处于消散区的卡牌无法被任何效果回收。
