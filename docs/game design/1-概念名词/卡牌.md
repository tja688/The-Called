<title>卡牌</title>

# 定义

游戏中战斗所需的基础单位，不同卡牌根据自身具体设计产生不同效果，一般拥有一个卡牌本身的效果，并可附加一个卡背

# 卡牌存放

关卡内，通过战斗中获得的卡牌，将存放在**牌组**里，战斗结束后牌组将复原到初始状态

# 卡牌与格位的关系

- 一个格位同时只容纳一张卡牌
- 卡牌一旦入场即属于打出它的一方，只会被特殊效果转移归属
- 卡牌的当前点数降为 0 时，该卡牌被移除出九宫格战场，进入弃牌堆；这是即时结算，每次结算后只要当前点数仍为 0 就会再次触发
- 因此 **保护** 会正常生效并消耗掉保护状态，但若此时卡牌点数仍为 0，会立即再次触发移除，卡牌仍会被移除
- 卡牌离场时，其对其他卡牌造成的**永久增减仍然保留**，其**驻场效果立即失效**

# 指代约定

卡面效果中的「己方」指该卡牌的所属方，「敌方」指另一方

# 稀有度

卡牌稀有度分为 白、蓝、金 三档

# 卡牌类型

无点数的是法术卡，有点数的是占场卡

## 占场卡

本身拥有点数，打出后会留在九宫格战场上的卡牌

## 法术卡

本身没有点数，打出后触发完效果直接进入弃牌堆的卡牌
