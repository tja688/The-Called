<title>点数</title>

# 定义

用于决定大小的数值

| 名称 | 定义 |
|-|-|
| 基础点数 | 卡牌的初始值 |
| 当前点数 | 卡牌经过增减的实际数值，下限为 0 |
| 总点数 | 一方所有战场卡牌的当前点数之和 |

# 当前点数的构成

```
当前点数 = max(0, 基础点数 + 永久增减 + 驻场增减)
```

| 来源 | 说明 | 何时失效 |
|-|-|-|
| 永久增减 | 入场效果、其它效果与覆盖造成的 +X / -X，如**污染格** | 卡牌离场前一直有效；施加者离场也不撤销 |
| 驻场增减 | **驻场** 类卡牌提供的光环 | 施加者离场或被封印时立即撤销 |

# 哪些数值参与比较

| 场景 | 使用的数值 |
|-|-|
| 格位鉴定 | 当前这一边的总点数，并且必须严格大于对方。不大于则这次鉴定没有结果 |
| 结案 | 双方的总点数，高者胜；总点数相同则占格多者胜。用于玩家无牌可出，以及怪物技能效果触发的特殊强制结算 |
| 覆盖判定 | 争夺双方各自的当前点数 |
| 效果条件（如「点数 ≤ 2 的敌方卡牌」） | 目标的当前点数 |
| 封印中的卡牌 | 不提供点数（总点数计 0），但覆盖判定仍使用其当前点数 |
