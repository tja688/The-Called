# 卡牌收集

1：对局结束收集  
  
当玩家击败怪物时，可获取此怪物的所有的“意图”卡牌



不会获取原本存在于场地中的卡牌或者其他卡牌



2：其他收集途径



见各自获取途径自身描述

3：新卡来源

60 张新卡中有 33 张可以从怪物处获得，其余建议进入初始牌组或商店轮换。献祭墓地方向依赖牌组，不适合做敌方意图，所以它的卡主要走额外奖励和初始牌组，建议神秘初始牌组以这个方向的白卡为骨架。
