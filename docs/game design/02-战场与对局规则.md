# 战场与对局规则

九宫格空间、点数比较、覆盖争夺与卡面词条。流程时机见 [[01-流程与元游戏#回合流程]]；卡牌如何入场见 [[03-卡牌与对局区域]]。

## 九宫格战场

### 战场布局

| **格1** | **格2** | **格3** |
| :---: | :---: | :---: |
| **格4** | **格5** | **格6** |
| **格7** | **格8** | **格9** |

格子按行优先，从左至右、从上至下编号。

### 位置术语

- **正交相邻**：上下左右紧邻的格子（如格5的正交相邻为格2、格4、格6、格8）
- **斜交相邻**：斜向紧邻的格子（如格5的斜交相邻为格1、格3、格7、格9）
- **角落格**：格1、格3、格7、格9
- **列格**：格1/格4/格7（左列）、格2/格5/格8（中列）、格3/格6/格9（右列）
- **排格**：格1/格2/格3（上排）、格4/格5/格6（中排）、格7/格8/格9（下排）
- **镜像格**：以格5为基点一一对应——格1↔格9、格2↔格8、格3↔格7、格4↔格6

## 点数

用于决定大小的数值。

### 名称

| 名称   | 定义                |
| :--- | :---------------- |
| 基础点数 | 卡牌的初始值            |
| 当前点数 | 卡牌经过增减的实际数值，下限为 0 |
| 总点数  | 一方所有战场卡牌的当前点数之和   |

### 当前点数的构成

```
当前点数 = max(0, 基础点数 + 永久增减 + 驻场增减)
```

| 来源 | 说明 | 何时失效 |
| :--- | :--- | :--- |
| 永久增减 | 入场效果、其它效果与覆盖造成的 +X / -X，如**污染格** | 卡牌离场前一直有效；施加者离场也不撤销 |
| 驻场增减 | **驻场**类卡牌提供的光环 | 施加者离场或被封印时立即撤销 |

### 哪些数值参与比较

| 场景                    | 使用的数值                       |
| :-------------------- | :-------------------------- |
| 强制结算                  | 先比双方总点数。仅 [[01-流程与元游戏#玩法]] 写明的平点场合，才再比实际占格 |
| 覆盖判定                  | 争夺双方各自的当前点数                 |
| 效果条件（如「点数 ≤ 2 的敌方卡牌」） | 目标的当前点数                     |
| 封印中的卡牌                | 不提供点数（总点数计 0），但覆盖判定仍使用其当前点数 |

## 覆盖

可以将点数大的卡牌打出到点数小的卡牌所在的格子上面，并将点数小的卡牌移入弃牌堆；点数大的卡牌扣除点数小的卡牌的点数后占据它原本所在的格子。若两张卡点数相同，则两张卡都移入弃牌堆，该格位变为空格位。

## 词条

将大量使用的前缀效果具体命名，以减少卡面描述的字量。

### 默认解读

- 卡面上未写明触发时机的效果，默认在**入场**时触发
- 未写明阵营的「回合开始」与「回合结束」，默认指**己方回合**
- 未写明针对场上还是手牌，默认只能选择场上的卡牌
- 效果指定的目标不存在时，效果不生效；卡牌仍正常入场，该效果要求的代价也不消耗

### 词条表

| 名称       | 效果                                          |
| :------- | :------------------------------------------ |
| **入场**   | 当卡牌入场时（被效果生成的卡牌同样触发）                        |
| **相邻**   | 正交相邻格上                                      |
| **污染格**  | 打出到该格上的卡牌点数 -1（一次性、永久计入）；污染格持续整场，同一格位不叠加    |
| **封印**   | 卡牌不提供点数，并且效果不生效，己方回合开始时移除**封印**（属于负面效果）     |
| **镜像**   | 两张卡牌处于镜像格上时                                 |
| **驻场**   | 当本卡在九宫格战场上                                  |
| **离场**   | 当本卡离开九宫格战场时                                 |
| **移除**   | 卡牌从当前所在区域进入弃牌堆                              |
| **保护**   | 当卡牌即将被移除时，改为移除保护状态（被覆盖移除时不生效）               |
| **返魂**   | 当卡牌被移除时，移除返魂状态，使卡牌回到手牌中（手牌满则进入弃牌堆）          |
| **献祭**   | 随机移除 X 张牌组内的卡牌（X 见卡面）；牌组不足 X 张时效果不生效        |
| **燃尽**   | 离场时不进入弃牌堆，无法被回收                             |
| **主动触发** | 玩家点击卡牌后产生对应效果，仅会生效一次                        |
| **计时X**  | **驻场**己方回合开始时 X-1；X 归零后触发卡牌效果，并将 X 重置为初始值。重置后继续倒数，本场可反复触发，没有次数上限 |
| **迅捷**   | 打出本卡不消耗出牌机会                                 |
| **转化**   | 将目标卡牌移除后，生成并打出一张指定卡牌（指定卡牌见卡面描述）             |

词条「计时」只描述对局里的倒数与触发。[[06-玩家卡牌与数值锚点#效果计价的固定参数]] 里同名的「计时X」只决定算负荷时按几次收费，不给本词条加上限。
