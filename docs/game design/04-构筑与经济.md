# 构筑与经济

大地图上的收藏、牌组编辑、卡背装配、负荷约束与金币循环。卡背数值设计见 [[06-玩家卡牌与数值锚点#数值锚点]]。

## 卡盒

玩家收藏卡牌的区域，获得的卡牌永久保留在卡盒中，不会清空。

### 内容

- 初始牌组的所有卡牌
- 战斗胜利奖励获得的玩家侧卡牌
- 持有的卡背
- 同名的白卡最多持有 3 张，蓝卡最多持有 2 张，金卡最多持有 1 张，再次获得时自动分解为金币
- 卡盒容量无上限

### 与牌组的关系

- 牌组是卡盒的子集
- 玩家在大地图上可随时打开卡盒编辑牌组；战斗进行中不可编辑

## 牌组

玩家带入关卡的 15 张卡牌集合（局内行为见 [[03-卡牌与对局区域#牌组·局内]]）。

### 构筑限制

- 构筑出的牌组有且只能拥有 15 张（上限与下限均为 15；关卡内因卡牌效果产生的增减不受此限制）
- 牌组的总负荷不超过 90
- 同名的白卡最多 3 张，蓝卡最多 2 张，金卡最多 1 张
- 构筑限制在编辑牌组时即时校验，不满足限制的牌组无法保存

### 初始牌组

玩家在游戏开始前选择的起始牌组，每个体系都有预组好的初始牌组（列表见 [[#初始牌组表]]）。

## 负荷

衡量卡牌占用牌组构筑容量的数值。

| 名称 | 定义 |
| :--- | :--- |
| 卡牌负荷 | 卡牌本体占用的负荷，不含卡背 |
| 卡背负荷 | 卡背附加给卡牌的负荷 |
| 整卡负荷 | 卡牌负荷与卡背负荷之和 |
| 总负荷 | 牌组内所有卡牌的整卡负荷之和 |

## 卡背

可以自由附加给任意卡牌的强化手段。每张卡牌只有一个卡背，默认为无效果的白板卡背，可以更换或卸下。

### 卡背负荷

卡背负荷为整数，范围为 0~4。同一个卡背装在任意卡牌上，其卡背负荷相同，不因所装卡牌的点数、效果或稀有度而改变。

### 获取

卡背来自关卡奖励，也可以在商店用金币购买；不同强度的卡背按关卡进度解锁。购买后存放在**卡盒**中。

### 卡背列表

数量上限指同一种卡背最多持有的个数，也就是最多能同时装备的卡牌数。

| 名称 | 效果 | 卡背负荷 | 数量上限 |
| :-- | :-- | :--- | :--- |
| 白板 | 无 | 0 | |
| 厚实 | 点数 +1 | 1 | |
| 洞见 | **入场**抽一张牌 | 1 | |
| 守护 | **入场**获得**保护** | 1 | |
| 巨大 | 点数 +2 | 2 | |
| 回生 | **入场**获得**返魂** | 2 | |
| 虔信 | **入场**获得 4 点信仰 | 2 | |
| 疾行 | **入场**额外出牌 1 次 | 3 | |
| 拾遗 | **入场**从弃牌堆指定回收 1 张 | 3 | |

| 磅礴 | 点数 +4 | 4 | |
| 生长 | 每回合结束时本卡点数 +2 | 4 | |

### 金币

#### 来源

- 卡盒中卡牌超出持有上限时，超出部分自动分解为金币
- 关卡胜利奖励

#### 用途

- 在**商店**消费
