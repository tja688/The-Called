# 怪物与关卡

怪物行动、关卡怪物配置与怪物方卡牌。流程衔接见 [[01-流程与元游戏]]；词条见 [[02-战场与对局规则#词条]]。

## 怪物意图

怪物没有手牌与牌组，其行动由**意图**驱动：意图是怪物每回合将要打出的那张牌，在玩家行动前确定并提前亮出，供玩家预判。

### 意图的构成

- 一条意图 = 打出一张指定卡牌。意图只显示要打哪张牌
- 意图不包含打出对象：不显示落在哪一格，不显示覆盖哪张牌，也不显示效果选中的目标。这些由怪物 AI 在怪物回合按当时的场面决定
- 一个怪物的意图由 1~4 条组成，按固定顺序逐回合循环执行；条数与内容按具体怪物设计，写在 [[#怪物数据]] 的意图列

### 与回合流程的关系

- 玩家回合的「确定意图」：按**意图顺序**亮出怪物本回合要打的那张牌，不亮落点和目标
- 怪物回合：执行本回合的意图。怪物 AI 先决定打出对象，再结算其效果
- 本回合的意图牌没有合法落点时，怪物跳过本回合的行动，意图顺序照常推进到下一条

## 怪物方的区域与资源

- 怪物有自己的弃牌堆与资源池（如信仰），规则与玩家相同
- 怪物没有手牌与牌组，作用于手牌或牌组的效果按「手牌与牌组为空」处理。因此抽牌、洗入牌组、打出手牌对怪物方不生效；献祭因牌组不足而不发生，它所在的整条能力都不生效

## 怪物技能

精英怪物和 BOSS 怪物拥有的全局效果。

| 名称 | 效果 |
| :-- | :-- |
| 干扰 | 关卡开始时（初始卡摆放之后），将九宫格战场上随机三个格位设定为**污染格** |
| 封锁 | 怪物回合开始时，随机**封印**一张九宫格战场上的玩家卡牌 |
