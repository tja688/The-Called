# 敌方与关卡

敌方行动、关卡怪物配置与敌方专用卡牌。流程衔接见 [[01-流程与元游戏]]；词条见 [[02-战场与对局规则#词条]]。

## 敌方意图

敌方没有手牌与牌组，其行动由怪物的**意图**驱动：意图是敌方每回合将要打出的那张牌，在玩家行动前确定并提前亮出，供玩家预判。

### 意图的构成

- 一条意图 = 打出一张指定卡牌。意图只显示要打哪张牌
- 意图不包含打出对象：不显示落在哪一格，不显示覆盖哪张牌，也不显示效果选中的目标。这些由后续的 AI 在敌方行动时按当时的场面决定
- 一个怪物的意图由 2~4 条组成，按固定顺序逐回合循环执行；条数与内容按具体怪物设计，写在 [[#怪物数据]] 的意图列

### 与回合流程的关系

- 玩家回合的「确定意图」：按**意图顺序**亮出敌方本回合要打的那张牌，不亮落点和目标
- 敌方回合：执行本回合的意图。AI 先决定打出对象，再结算其效果

## 怪物技能

精英怪物和 BOSS 怪物拥有的全局效果。

| 名称 | 效果 |
| :-- | :-- |
| 干扰 | 关卡开始时，将九宫格战场上随机三个格位设定为**污染格** |
| 封锁 | 敌方回合开始时，随机**封印**一张九宫格战场上的玩家卡牌 |
