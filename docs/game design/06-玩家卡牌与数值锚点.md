玩家侧卡表由内容文件生成，负荷定价标准见下文。构筑约束见 [[04-构筑与经济]]；词条见 [[02-战场与对局规则#词条]]。

## 玩家侧卡牌

### 体系总览

体系是卡牌的主题分类，决定初始牌组的构成；卡牌的获取不受体系限制

| 体系  | 特色                   |
| :-- | :------------------- |
| 科学  | 为卡牌添加解析标记，使卡牌获得增益或减益 |
| 神秘  | 镜像与献祭                |
| 宗教  | 信仰、保护、移除、封印          |

### 科学体系
#### 特色
为卡牌添加解析标记，根据带标记的卡牌数量使卡牌获得增益或减益，拥有超模大点数，计时机制

#### 解析标记
标记一张卡牌，该卡牌会响应需要解析标记的效果。解析标记不叠加：一张卡牌要么有、要么没有，重复添加无效

## 数值锚点

### 数值锚点

```
卡牌负荷 = max(4, 向上取整[B(P) + E − D − R])
```

### 稀有度优惠 R
| 稀有度 | 优惠       |
| :-- | :------- |
| 白卡  | R ＝ 0    |
| 蓝卡  | R =  0~1 |
| 金卡  | R ＝ 1~2  |

### 独立定价与自由装配
| 序号  | 规则                                                                              |
| :-- | :------------------------------------------------------------------------------ |
| 1   | 巨大卡背固定＋2点、2负荷，不因本体的翻倍、复制或回收效果加价                                                 |
| 2   | 整卡负荷始终为卡牌负荷加卡背负荷，不收组合附加费                                                        |
| 3   | 12点卡牌可以装备加点卡背；例如装备巨大卡背后为14点、装备＋4点卡背后为16点，均允许                                    |
| 4   | 不因卡牌与卡背存在收益放大而禁止装配；每张卡最多装备一个卡背，仍受整副牌90负荷限制                                      |
| 5   | 本定价文档不额外规定「外部复制不继承卡背」或「卡背效果每场只触发一次」；触发与继承按对应效果规则处理，不为限制卡背价格而新增通用禁令              |
| 6   | 设计卡背本身时，按价目表计算其效果并确定0~4的固定价格；若设计强度超出该区间，调整该卡背自身的效果，而不是对特定搭配加价或禁止装配；0负荷卡背不提供正向收益 |

### 测试与调整
| 事项   | 内容                                                   |
| :--- | :--------------------------------------------------- |
| 报价性质 | 确定报价是统一设计标准，不宣称能精确预测所有组合的胜率；不使用区间报价，测试失败时修改统一价目或效果规格 |
| 测试范围 | 保持15张／90负荷，测试基础白板、持续成长、额外出牌、回收复制四类构筑                 |
| 记录项  | 在初始0、1、2、3张怪物卡占场的关卡，记录有效触发次数、核心上手率、抢结算次数与胜负           |
| 调整阈值 | 若实际重复触发显著超过2次，调整该类效果的统一计价次数或明确触发上限                   |
| 数值锚点 | 卡牌的基础点数最高12（设计锚点，允许些微超模或亏模）；卡背负荷固定0~4；两者独立计价、自由组装    |
| 调整方针 | 组合过强时调整组件本身，不新增装配后的12点上限、搭配加价或装配禁令                   |

### 效果计价的固定参数

这张表只回答「算负荷时，这种效果按几次收费」。次数是估价口径，不改写 [[02-战场与对局规则#词条]]，也不表示卡牌在对局里只能触发这么多次。

表中的「计时X」和词条「计时」同名，但是两件事：

- 词条「计时」：己方回合开始倒数，归零后触发，再把 X 重置为初始值。重置后继续倒数，本场反复触发，没有次数上限。
- 本参数：收费时，把「持续效果大约按 2 次估价」折到间隔为 X 的效果上。次数＝max(1，向下取整[2／X])，X 为正整数。X 为 2 或 3 时，收费次数都是 1。卡面负荷可以按这 1 次来定；实战里每次归零仍然触发。

下文价目和试报价里的「计时 2 按 1 次」，指的都是这个收费次数。

| 参数            | 固定取值                                  |
| :------------ | :------------------------------------ |
| 入场或离场一次性效果    | 各计1次                                  |
| 每回合开始／结束，驻场反应 | 计2次                                   |
| 每当打牌／覆盖／离场    | 计2次                                   |
| 计时X（只用于计价）    | 次数＝max(1，向下取整[2／X])，X为正整数。不限制词条的实际触发 |
| 相邻、同排、同列、全体目标 | 无数量上限按3个；有上限N按min(N，3)    |
| 镜像目标          | 1个                        |
| 手牌批量增减        | 按2张最终打出的牌；上限N时取min(N，2)   |
| 弃牌数量或累计死亡数    | 3个；上限N时取min(N，3)          |
| 任意目标当前点数      | 按6点；有点数上限K时取min(K，6)      |
