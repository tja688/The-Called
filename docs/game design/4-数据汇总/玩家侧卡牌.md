# 玩家侧卡牌

## 名字怎么起

占场卡有点数，打出去会留在格子上。名字写成一个人，或一件能摆在桌上的东西，比如神官、修女、显微镜。

法术卡没有点数，效果放完就进弃牌堆。名字写成一个做法、一句祷告或一次念头，不写成某个人，也不写成某件器物。

## 体系总览

体系是卡牌的主题分类，决定初始牌组的构成；卡牌的获取不受体系限制

| 体系 | 特色 |
|-|-|
| 科学 | 为卡牌添加解析标记，使卡牌获得增益或减益 |
| 神秘 | 镜像与献祭 |
| 宗教 | 信仰、保护、移除、封印 |
