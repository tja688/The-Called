# 敌方侧卡牌

| 卡牌名称 | 卡牌效果 | 点数 |
|-|-|-|
| 失控机械 | **驻场**为打出到**相邻**的敌方卡牌添加解析标记 | 5 |
| 大力打击 | 无 | 5 |
| 逼近 | **入场**有**相邻**玩家卡牌时，本卡点数+2 | 2 |
| 偷袭 | **入场**一张随机**相邻**玩家卡牌点数-1 | 2 |
| 蜂巢 | **驻场**回合结束时，在一个与本卡**相邻**的空格生成一张「工蜂」 | 3 |
| 工蜂 | 无效果，**燃尽** | 1 |
| 古镜 | **驻场**每当一张己方卡牌打出到敌方卡牌的**镜像**格，使其点数+2 | 4 |
| 鸦巢 | **驻场**每当一张占场卡**离场**，本卡点数+2 | 2 |
| 讲经台 | **驻场**回合开始时，获得 2 点信仰 | 3 |
| 解剖台 | **驻场**每当一张敌方卡牌获得**解析标记**，本卡点数+1 | 5 |
| 双生镜 | **驻场**若本卡**镜像**格上有己方卡牌，本卡点数+2 | 3 |
| 镜影 | 无效果，**燃尽** | 触发卡基础点数的一半，向下取整 |
| 缄默刑柱 | **驻场**每当一张敌方卡牌被**封印**，本卡点数+2 | 5 |
| 大钟 | **计时3**：满足特殊强制结算条件 | 6 |
| 发条卫兵 | **驻场**己方的大钟不能被点数小于 10 的卡牌覆盖 | 4 |
| 应召之核 | 本卡不能被点数小于 14 的卡牌覆盖；**驻场**回合开始时，本卡点数+1 | 8 |
| 呓语 | 被玩家抽到时，使一张玩家场上卡牌点数－2，随后移除；不占手牌、不消耗出牌机会、不补抽 | 无 |
| 残影 | 无效果，**燃尽**。占场类生成物，点数见生成效果 | 见生成效果 |
