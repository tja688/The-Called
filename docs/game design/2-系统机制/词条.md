# 定义

将某个大量使用的前缀效果进行具体命名，以减少卡面描述的字量。卡面上未写明触发时机的效果，默认在**入场**时触发；未写明阵营的「回合开始」与「回合结束」，默认指**己方回合**

| 名称 | 效果 |
|-|-|
| **入场** | 当卡牌入场时（被效果生成的卡牌同样触发） |
| **相邻** | 正交相邻格上 |
| **污染格** | 打出到该格上的卡牌点数-1（一次性、永久计入）；污染格持续整场，同一格位不叠加 |
| **封印** | 卡牌不提供点数，并且效果不生效，己方回合开始时移除**封印**（属于负面效果） |
| **镜像** | 两张卡牌处于镜像格上时 |
| **驻场** | 当本卡在九宫格战场上 |
| **离场** | 当本卡离开九宫格战场时 |
| **移除** | 卡牌从当前所在区域进入弃牌堆 |
| **保护** | 当卡牌即将被移除时，改为移除保护状态（被覆盖移除时不生效） |
| **返魂** | 当卡牌被移除时，移除返魂状态，使卡牌回到手牌中（手牌满则进入弃牌堆） |
| **献祭** | 随机移除X张牌组内的卡牌（X见卡面）；牌组不足 X 张时效果不生效 |
| **燃尽** | 离场时不进入弃牌堆，无法被回收 |
| **主动触发** | 玩家点击卡牌后产生对应效果，仅会生效一次 |
| **计时X** | 己方回合开始时，X-1，当X归零后，触发卡牌效果，并将X重置为初始值 |
| **迅捷** | 打出本卡不消耗出牌机会 |
