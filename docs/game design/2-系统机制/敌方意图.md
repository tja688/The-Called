<title>敌方意图</title>

# 定义

敌方没有手牌与牌组，其行动由怪物的**意图**驱动：意图是敌方每回合将要执行的动作，在玩家回合开始时确定并提前亮出，供玩家预判。

# 意图的构成

- 一条意图 = 往某个格位打出一张敌方侧卡牌，与玩家出牌同构（不包括打出到具体哪个格位）
- 一个怪物的意图由 2\~4 条组成，按固定顺序逐回合循环执行；条数与内容按具体怪物设计，写在 `4-数据汇总/怪物数据.md` 的「意图顺序」列

# 与回合流程的关系

- 玩家回合开始：按**意图顺序**确定敌方本回合的意图，并提前亮出
- 敌方回合：执行本回合的意图，随后结算其效果

# 落位与目标

1. **通用落位**：落在与玩家卡相邻数最多的空格，并列时取格位编号最小者；没有空格时，覆盖可覆盖的点数最高的玩家卡；仍无合法格位则跳过该意图，意图顺序照常推进。
2. **覆盖优先**：标注"覆盖优先"的卡先尝试覆盖可覆盖的点数最高的玩家卡，不能覆盖时再按通用落位。
3. **目标选择**：作用于玩家卡的效果选点数最高的合法目标；作用于己方的增益选点数最高的己方卡；写明"随机"的照常随机。
4. **资源类效果**：敌方没有手牌与牌组，抽牌、献祭、手牌强化、洗入牌组对敌方不生效。敌方拥有独立的信仰值，规则与玩家相同，并在界面上公开显示。
5. **专属卡的指代**：敌方专属卡按「指代约定」书写，卡面上的"己方"指敌方自己，"敌方"指玩家。

# 各怪物的落位规则

| 怪物 | 落位规则 |
|-|-|
| 巡检蜂群 | 全部按通用落位；测绘员以点数最高的玩家卡为中心挂标记；收容钳移除"有标记且不超过 3 点"的玩家卡中点数最高者 |
| 布道团 | 通用落位；审判官移除"点数最高且没有保护"的玩家卡 |
| 镜中人 | 镜匠：优先落在点数最高玩家卡的镜像空格；银镜：优先落在点数最高敌方卡的镜像空格；双生子：优先落在任一敌方卡的镜像空格；都不满足时按通用落位 |
| 锈蚀巨像 | 三张均为覆盖优先 |
| 食腐鸦群 | 通用落位 |
| 解剖学家 | 收容钳、标本柜：通用落位；攻击炮台、激光扫描仪：优先落在与玩家卡相邻最少的空格 |
| 缄默修会 | 告解神父：落在点数最高玩家卡的相邻空格，并封印该卡；驱魔人：通用落位；大审判长：优先落在与玩家卡相邻最少的空格 |
| 镜渊魔女 | 黑镜：在镜像格为空的空格中，选与玩家卡相邻最多者（布陷阱）；夺舍者：优先打在点数最高的己方镜影上并继承其点数；星盘：优先落在己方卡的镜像空格 |
| 钟楼守望者 | 圣殿守卫：优先落在大钟的相邻空格；计时器：优先落在点数最高玩家卡的镜像空格；穿甲钻头：覆盖优先 |
| 呼唤者 | 测绘员、数据核心：通用落位；彼岸花、圣女：优先落在与玩家卡相邻最少的空格 |
