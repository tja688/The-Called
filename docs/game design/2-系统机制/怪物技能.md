# 定义

精英怪物和BOSS怪物拥有的全局效果

| 名称 | 效果 |
|-|-|
| 干扰 | 关卡开始时，将九宫格战场上两个格子设定为**污染格** |
| 封锁 | 敌方回合开始时，随机**封印**一张九宫格战场上的玩家卡牌 |
| 活体解析 | 敌方回合结束时，为一张随机的、未持有标记的玩家卡牌添加**解析标记** |
| 镜像反射 | 每当一张玩家占场卡入场，若其镜像格为空，敌方在该格生成一张「镜影」（点数为该卡基础点数的一半，向下取整，**燃尽**） |
| 呼唤 | **计时2**：将点数最低的一张玩家占场卡转为敌方所有（并列时取格位编号最小者；归属转移不是移除，保护无效） |
| 呓语 | 敌方回合结束时，将一张「呓语」洗入玩家牌组 |
