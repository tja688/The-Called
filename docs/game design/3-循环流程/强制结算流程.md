# 强制结算具体流程

三种条件分开记。格位走鉴定，资源和特殊走结案。记下来的条件不在记下的那一步宣布胜负。

## 触发类型

| 类型 | 触发规则 |
|-|-|
| 格位强制结算 | 九宫格被卡牌填满时 |
| 资源强制结算 | 当玩家无可使用卡牌时 |
| 特殊强制结算 | 由卡牌，怪物效果触发 |

## 格位鉴定

九格都有牌之后，对局不结束。铺满记在当前这一边的行动结算里，等这一边的回合结束。从下一边开始，每换一边，在这一边的回合开始、回合开始效果之后，鉴定一次。

鉴定只看当前这一边：该边的总点数严格大于对方，该边获胜，本回合不再行动。不大于，包括落后和相等，这次鉴定没有结果。回合继续，这一边仍然出牌。出牌可以改变双方总点数。换边之后，下一边在自己的回合开始再鉴定一次。

如此交替，直到某一边在自己的回合开始时严格领先。领先的是对方、但现在还没轮到对方，不会让对方直接获胜。

格位条件记下之后保留。后来有牌离场、格子重新变空，鉴定也不停，直到分出胜负，或被下面的结案打断。

例：我方 19、对方 18 时铺满，我方回合结束。对方回合开始，18 不大于 19，鉴定没有结果，对方出牌，变成 19–21。我方回合开始，19 不大于 21，我方出牌，变成 26–21。对方回合开始，21 不大于 26，对方出牌，变成 26–25。我方回合开始，26 大于 25，我方获胜。

## 结案

资源强制结算和特殊强制结算仍按原判定。条件在回合结束记下。大钟在敌方回合开始的计时里记下，并在同一次回合开始结案。

结案比较双方总点数，高的一方获胜。总点数相同，占格多的一方获胜。占格也相同，当前即将开始回合的一方判负。结案成立后，当次回合开始就分出胜负，不再给出牌。

格位与资源或特殊同时成立时，走结案，不做格位鉴定。
