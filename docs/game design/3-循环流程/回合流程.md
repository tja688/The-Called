# 每回合具体流程

回合流程固定为以下阶段，前一阶段未完成不得进入下一阶段：

| 顺序 | 规则层描述 |
|-|-|
| 1.**玩家回合开始** | 玩家回合开始，触发所有玩家方回合开始时的效果，若已满足强制结算条件，此时己方总点数大于敌方总点数，己方胜利敌方失败 |
| 2.**确定意图** | 按**意图顺序**确定敌方本回合的意图 |
| 3.**玩家抽牌** | 从牌组抽 1 张卡牌作为手牌。手牌达到上限时不抽取，牌组为空时不抽取 |
| 4.**玩家行动** | 玩家可选择打出一张牌到格位，或不打出卡牌主动结束回合。打出的卡牌立即结算其效果，随后消耗出牌机会。 |
| 5.**玩家回合结束** | 玩家回合结束，触发所有玩家方回合结束时的效果，依次检查强制结算条件 |
| 6.**敌方回合开始** | 敌方回合开始，触发所有敌方回合开始时的效果，若已满足强制结算条件，此时己方总点数大于敌方总点数，己方胜利敌方失败 |
| 7.**敌方行动** | 敌方执行本回合的意图，并立即结算其效果 |
| 8.**敌方回合结束** | 敌方回合结束，触发所有敌方回合结束时的效果，依次检查强制结算条件 |

同一阶段内多张卡同时触发效果时，按格位编号从小到大（格1 → 格9）依次结算

回合流程会一直循环，直到一方胜利
