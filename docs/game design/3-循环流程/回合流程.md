# 每回合具体流程

回合流程固定为以下阶段，前一阶段未完成不得进入下一阶段：

| 顺序 | 规则层描述 |
|-|-|
| 1.**玩家回合开始** | 玩家回合开始，先触发所有玩家方回合开始时的效果。若已满足资源强制结算或特殊强制结算，按结案判定分出胜负。若只满足格位强制结算，做一次格位鉴定：玩家总点数严格大于敌方则玩家获胜；否则鉴定没有结果，回合继续 |
| 2.**确定意图** | 按**意图顺序**确定敌方本回合的意图 |
| 3.**玩家抽牌** | 从牌组抽 1 张卡牌作为手牌。手牌达到上限时不抽取，牌组为空时不抽取 |
| 4.**玩家行动** | 玩家可选择打出一张牌到格位，或不打出卡牌主动结束回合。打出的卡牌立即结算其效果，随后消耗出牌机会。 |
| 5.**玩家回合结束** | 玩家回合结束，触发所有玩家方回合结束时的效果，依次检查三种强制结算条件并记录。这一步不宣布胜负 |
| 6.**敌方回合开始** | 敌方回合开始，先触发所有敌方回合开始时的效果。若已满足资源强制结算或特殊强制结算，按结案判定分出胜负。若只满足格位强制结算，做一次格位鉴定：敌方总点数严格大于玩家则敌方获胜；否则鉴定没有结果，敌方仍然行动 |
| 7.**敌方行动** | 敌方执行本回合的意图，并立即结算其效果 |
| 8.**敌方回合结束** | 敌方回合结束，触发所有敌方回合结束时的效果，依次检查三种强制结算条件并记录。这一步不宣布胜负 |

同一阶段内多张卡同时触发效果时，按格位编号从小到大（格1 → 格9）依次结算

回合流程会一直循环，直到一方胜利
