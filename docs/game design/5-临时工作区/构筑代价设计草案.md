# 一、构筑约束

| 项目 | 规则 |
|-|-|
| 牌组 | 固定15张，总负荷不超过90，包含卡背 |
| 同名白／蓝／金卡 | 分别最多3／2／1张 |
| 不同名卡 | 无额外稀有度数量限制，仍受张数和负荷约束 |
| 跨体系 | 不加费 |
| 裸卡最低负荷 | 4 |
| 白板设计范围 | 1～12点，高于12点暂不设计 |
| 卡背附加负荷 | 整数0～4，每张卡最多一个卡背 |
| 检查时机 | 战斗前；战斗内生成、复制、移除不重新检查构筑 |

12点只限制裸卡的基础点数，包括白板和效果卡的裸本体。卡背加点、卡牌效果和战斗成长均可使点数超过12，不截断，也不限制装配。本版不再设计14、17、20、23点裸白板档。

# 二、统一计算公式

为让每种效果有确定价格，改为「本体查表＋效果固定加价」，不再将全部效果合并后查整卡曲线。

```
裸卡负荷＝max(4，向上取整[B(P)＋E－D－R])
装备后负荷＝裸卡负荷＋卡背附加负荷
```

- P：无效果本体点数，法术为0。
- B(P)：本体原始价格，不提前套最低4。
- E：正向效果附加负荷之和。
- D：必要的实际付出给予的折扣，全卡最多1。
- R：白卡0；符合条件的蓝卡1；金卡1。
- 小数仅用于设计计算，所有项目合并后向上取整一次，卡面只显示整数。

本体的高点数效率保留；特殊效果为干扰、配合和功能付费，不再同时领取高档曲线折扣。后文效果表中的「＋2」就是增加2负荷，不是2点等效价值。

法术B(0)＝0。1～3点原始价格主要供效果卡计算，不建议做纯白板。7、9、11点与下一点数同价，通常用于调整效果卡本体，不建议制造无区别的劣势白板。

蓝卡的优惠来自条件效果，因此纯白板与白卡同价。金卡通常少1负荷，但不突破最低4。

## 每一档提升的逻辑

| 白／蓝白板负荷 | 最高白板点数 | 增量 | 逻辑 |
|-|-|-|-|
| 4 | 4 | 基准 | 斥候：4点白板＝4负荷 |
| 5 | 5 | ＋1点 | 低档每1负荷换1点 |
| 6 | 6 | ＋1点 | 与90／15＝6的平均构筑预算衔接 |
| 7 | 8 | ＋2点 | 补偿预算集中与其他卡位降配 |
| 8 | 10 | ＋2点 | 中高档继续获得效率优势 |
| 9 | 12 | ＋2点 | 本轮白板终点，不向上扩展 |

例如6＋6＋6负荷对应18点白板；8＋5＋5负荷对应20点。同样三个卡位和18负荷，集中配置多2点潜在收益，但更依赖高点数牌上手。

效果卡可以超过9负荷，因为额外购买效果，不代表开放更大白板。

# 四、效果计价的固定参数

以下是假定的定价基准，不是新增的战斗触发上限，不能逐卡选择更便宜的情境。

| 参数 | 固定取值 |
|-|-|
| 入场或离场一次性效果 | 各计1次 |
| 每回合开始／结束，驻场反应 | 计2次 |
| 每当打牌／覆盖／离场 | 计2次 |
| 计时X | 次数＝max(1，向下取整[2／X])，X为正整数 |
| 相邻、同排、同列、全体目标 | 无数量上限按3个；有上限N按min(N，3) |
| 镜像目标 | 1个 |
| 手牌批量增减 | 按2张最终打出的牌；上限N时取min(N，2) |
| 弃牌数量或累计死亡数 | 3个；上限N时取min(N，3) |
| 任意目标当前点数 | 按6点；有点数上限K时取min(K，6) |

效果X按卡面数值计价；实战溢出伤害不退负荷。能同时生效的效果相加；互斥分支取最贵的一支。复合效果已经包含的抽牌、入场等功能不重复收费。

# 五、效果固定价目表

## 1. 点数与位置

| 效果 | 附加负荷E | 实际收益说明 |
|-|-|-|
| 自身或一张己方场上卡＋X | ＋X | 直接增加X点 |
| 一张敌方卡－X | ＋X | 实际最多削减目标现有点数 |
| 多目标各＋X／－X | ＋X×计价目标数 | 只算一次多目标费用 |
| 一张手牌＋X | ＋0.5X | 需要以后打出，按场上强化半价 |
| 多张手牌各＋X | ＋0.5X×计价手牌数 | 默认2张兑现 |
| 自身点数翻倍 | ＋P | 额外获得裸本体P点，强化放大见卡背章节 |
| 一张其他卡点数翻倍 | ＋6 | 按6点目标计价 |
| 重置一张己方或敌方卡点数 | ＋3 | 固定功能价，按一次有利重置估值，不随实战目标变价 |
| 相邻、镜像、同排、同列条件 | ＋0 | 只为其实际执行的效果付费 |
| 主动触发一次 | ＋0 | 触发方式不收费，执行内容正常收费 |

8点白板为7负荷；4点本体＋入场自身加4为8负荷。后者多了入场与重触发接口。若二者在规则上完全等价，直接设计为白板，不制造无意义价差。

## 2. 覆盖、堆叠与防护

| 效果 | 附加负荷E | 说明 |
|-|-|-|
| 普通覆盖、相等覆盖 | ＋0 | 基础规则 |
| 覆盖后少扣X点 | ＋min(X，6) | 按6点目标计算 |
| 覆盖后不扣自身点数 | ＋6 | 比普通覆盖额外多保留6点 |
| 堆叠己方卡，继承点数并移除旧卡 | ＋2 | 为保留格数、集中点数、离场配合收费；旧点数不重复购买 |
| 不能被小于K点的卡覆盖 | ＋0.5×max(0，K－P) | 只为新增门槛付费；保留现有大于或等于覆盖的边界 |
| 移除一张敌方卡 | ＋6 | 不再另加引擎破坏费 |
| 移除点数不超过K的敌方卡 | ＋min(K，6) | 有限制版按固定目标口径 |
| 封印一张敌方卡，持续按现有词条 | ＋3 | 含短期效果失效与抢结算价值 |
| 清除一张己方卡的一个负面效果 | ＋1 | 带补偿分支时取较贵分支 |
| 为一张己方卡增加保护 | ＋1 | 不挡覆盖，也救不了持续为0点的卡 |
| 为一张己方卡增加返魂 | ＋2 | 条件触发回手，不含再次免费打出 |
| 将一个格位设为污染格 | ＋2 | 1点削减×2次有效使用 |
| 将一张卡移动到一个合法空格 | ＋2 | 不改点数、不触发入场；仅为思路中的移动效果提供报价 |

覆盖例子：6点覆盖敌方4点，己方剩2、敌方减4，分差改善6，不是10。堆叠例子：4点新卡吞掉己方6点旧卡，己方由6变10，直接收益只有4，另付2购买堆叠功能。

| 查看顶部3张，选择1张入手 | ＋2 | 含选中的1张；其余放回，若移除剩余牌不另折价 |
| 从整副牌组指定检索1张入手 | ＋3 | 含抽到该牌，不再加抽牌费 |
| 从己方弃牌堆指定1张回手 | ＋3 | 不含再次打出 |
| 将1张指定弃牌洗回牌组 | ＋1 | 不立即入手 |
| 将本卡1张复制洗入牌组 | ＋1 | 不立即入手 |
| 生成1张P点白板到空格 | ＋B(P)＋1 | 本体原始价加额外占格费，不套最低4 |
| 在空格生成1张己方卡的完整复制 | ＋8 | 一次一张、非递归；含本体及复制品一次入场 |
| 从弃牌堆指定1张占场卡直接入场 | ＋8 | 含本体与一次入场，不再叠加回手费 |

完整复制8负荷报价只用于有限版本：复制品不得继续生成或复活同一复制链。这是建议的新效果规格，不是对现有投影仪的默默改动。无限递归版本不纳入本轮设计，不能用有限费用购买无限收益。

生成白板与完整复制二选一计价，不能相加。繁衍按其生成模板报价乘触发次数。纯法术使用B(0)＝0，最后执行最低4，不另收一个空白本体费。

## 6. 敌方专属效果的难度报价

敌方没有构筑负荷，下列只作为关卡设计的比较单位，不从玩家90负荷里扣除。

| 效果 | 固定难度价 | 规格 |
|-|-|-|
| 洗入1张负面卡 | ＋2 | 负面卡定义为抽到时使一张玩家场上卡－2，随后移除；无目标则无削减，不消耗出牌机会、不补抽 |
| 移动攻击 | ＋2＋X | 移动一次并削减一个目标X点，两项相加 |
| 繁衍 | B(P)＋1 | 每次生成一张P点白板；持续版乘2 |
| 空场／初始1、2、3张卡 | 按实际初始卡本体与效果分别计算 | 初始数量改变结算速度，不能只把数量当成固定点数 |

洗入其他类型的负面卡须先定义具体惩罚，不能让同一个＋2报价涵盖任意强度的诅咒。此处新增的是可计价的候选规格，不自动加入现有怪物设计。

# 六、负面代价与稀有度

## 负面代价D

| 必要付出 | 减负荷 |
|-|-|
| 自身或另一张己方场上卡失去X点 | min(1，0.5X) |
| 一张己方手牌失去X点 | min(1，0.25X) |
| 消耗X信仰 | min(1，0.25X) |
| 消耗全部信仰 | 1，标准按4点 |
| 随机献祭牌组X张 | 0，弃牌体系能将其变成收益 |
| 移除自选手牌或场上卡 | 0，可能触发离场或清理负面牌 |
| 燃尽 | 0，不用永久收藏损失交换战斗超模 |
| 相邻、镜像、标记、数量等条件 | 0，条件优势交给蓝卡优惠 |

D累加后全卡最多减1。重复效果的消耗按相同计价次数累计。只有付出是获得收益的必要前提时才减价：没有目标也能获得全部收益，则D＝0。霸占者若能在无相邻己方卡时正常打出，就不能用那个可避开的－2获得折价。

## 稀有度优惠R

- 白卡：0。
- 蓝卡：具有依赖标记、位置、资源门槛、延迟或后续事件的效果，且这些条件效果原始E合计至少为2，优惠1。否则0。全卡只优惠一次；无条件即时效果不享受优惠。
- 金卡：1，全卡只优惠一次。

这样蓝卡的超模放在条件效果上，金卡的超模放在构筑效率上。不额外叠加第二份高费奖励。条件效果低于2不给蓝卡优惠，避免很小的条件把整张本体打折。

# 七、卡背固定0～4负荷

卡牌与卡背分别定价、自由组装，不使用整卡升档差价。相同卡背装在任意卡牌上价格相同，固定为0～4负荷，且不再次领取稀有度优惠。

| 卡背负荷 | 卡背规格示例 | 每档提升逻辑 |
|-|-|-|
| 0 | 默认无效果、纯外观 | 没有正向战斗收益 |
| 1 | 本体＋1；或入场抽1张；或入场获得保护 | 购买1负荷效果 |
| 2 | 巨大卡背：本体＋2；或入场获得返魂；或入场获得4信仰 | 购买2负荷效果 |
| 3 | 入场额外出牌1次；或指定回收1张弃牌；或封印1张敌人 | 购买3负荷效果 |
| 4 | 本体＋4；或每回合结束自身＋2；或入场抽1张并额外出牌1次 | 购买4负荷效果 |

除了巨大卡背，其余是候选设计，尚未加入卡背列表。表中的「或」表示不同卡背方案，不是同一个卡背自带多个选择。返魂、保护只在入场赋予一次，不会自动补充状态。

卡背点数按每点1负荷收费，不继承大白板的批量折扣，因为它能精确强化玩家选中的现成卡。巨大卡背固定增加2负荷。

## 独立定价与自由装配

1. 巨大卡背固定＋2点、2负荷，不因本体的翻倍、复制或回收效果加价。
2. 装备后负荷始终为裸卡负荷加卡背负荷，不收组合附加费。
3. 12点裸卡可以装备加点卡背。例如装备巨大卡背后为14点，装备＋4点卡背后为16点，均允许。
4. 不因卡牌与卡背存在收益放大而禁止装配。每张卡最多装备一个卡背，仍受整副牌90负荷限制。
5. 本定价文档不额外规定「外部复制不继承卡背」或「卡背效果每场只触发一次」。触发与继承按对应效果规则处理，不为限制卡背价格而新增通用禁令。
6. 设计卡背本身时，按价目表计算其效果并确定0～4的固定价格；若设计强度超出该区间，调整该卡背自身的效果，而不是对特定搭配加价或禁止装配。0负荷卡背不提供正向收益。

组合放大是自由构筑的收益来源。若测试发现某个组合过强，调整卡牌或卡背自身的统一价格、数值或效果描述；同一个组件对所有搭配采用同一规则。

| 装配例子 | 计算 | 装备后负荷 |
|-|-|-|
| 白色斥候4点＋巨大卡背 | 4＋2 | 6 |
| 白色10点白板＋巨大卡背 | 8＋2 | 10 |
| 金色勇士10点＋巨大卡背 | 7＋2 | 9 |
| 金色祭坛5点，献祭3张后翻倍＋巨大卡背 | 裸卡5＋翻倍5－金卡1＝9，卡背固定2 | 11 |
| 白色12点白板＋巨大卡背，装备后14点 | 9＋2 | 11 |
| 白色12点白板＋4点卡背，装备后16点 | 9＋4 | 13 |

# 九、测试与调整

本版的确定报价是统一设计标准，不宣称能精确预测所有组合的胜率。价格不再使用「1～2」「视情况另加」等区间；测试失败时修改统一价目或效果规格。

保持15张／90负荷，测试基础白板、持续成长、额外出牌、回收复制四类构筑。在初始0、1、2、3张敌方占场的关卡记录有效触发次数、核心上手率、抢结算次数和胜负。若实际重复触发显著超过2次，调整该类效果的统一计价次数或明确触发上限。

裸卡基础点数最高12；卡背固定0～4负荷；两者独立计价、自由组装。组合过强时调整组件本身，不新增装配后的12点上限、搭配加价或装配禁令。前文有限复制仍只是该效果报价所对应的建议规格，不构成卡背装配限制。
