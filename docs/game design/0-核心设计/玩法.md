# 玩法

### TheCall（暂定）是一款玩家与敌方NPC进行非对称卡牌竞技游戏。



双方轮流打出卡牌在九宫格盘面上，敌方有技能/在场地上预摆放的卡牌，但是需要呈现下一张打出的卡牌意图，玩家每场对战自组卡组进行挑战。



对局有两种收场。

九宫格被铺满之后不立刻分胜负。此后每换一边，在这一边的回合开始时做一次格位鉴定：这一边的总点数严格大于对方，这一边才获胜。不大于就没有结果，这一边照常出牌，双方总点数可以继续变。换边后再鉴定，直到某一边在自己的回合开始时严格领先。

玩家无可使用的卡牌，或卡牌、怪物效果触发特殊强制结算时，仍在回合开始结案：总点数高的一方获胜。总点数相同，占格多的一方获胜。这两种和格位鉴定不是同一次判定。
