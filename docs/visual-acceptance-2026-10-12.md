# 二维表现重构验收记录

本次将主菜单、地图、卡盒与构筑、对局改为统一的二维俯视表现。参考为 [Achroma](https://game.unsnow.online/ach/)。参考站通过浏览器实际启动，并检查其公开的 `engine.js`、`world.js`、`ui.js` 与 `combat.js`。参考源码只用于分析，项目中没有导入其代码或图片。

## 参考机制与当前实现

| 已观察的参考机制 | The Called 的实现 |
| --- | --- |
| 480×270 场景 Canvas 关闭平滑，UI 单独绘制 | `Atmosphere` 使用约三倍最近邻放大；DOM 中文与操作控件保持清晰 |
| 黑至暖白的有限灰阶，灰色地砖与墙缘 | 遗迹房间、九宫格石室、地面接缝、裂纹与碎石 |
| 红 `#ff3d5a`、青 `#35f0ff`、金 `#ffcf3a`、紫 `#b56bff` | 玩家与怪物的状态、卡牌学派、选中与可操作格位 |
| Bayer 4×4 抖动替代平滑光晕 | 主菜单灰阶山脊、遗物周围的离散光点 |
| 慢速旋转术式、漂浮遗物、灰烬 | 主菜单像素符文环与自制遗物，所有页面的稀疏颗粒 |
| 入场位移、短时闪白、碎屑、伤害文字 | 落牌出现、格位冲击、红青像素碎屑、点数增减浮字 |

共享卡面包含固定内容 ID 的自制像素符号、当前点数、学派和真实规则文字。手牌、战场与怪物意图在同一画面中显示。点击与拖动使用同一份内核选项；能力目标、弃牌堆选择和法术施放继续提交原 `PcdOption.id`。

构筑中，选中一个位置后可以直接替换卡牌，保留该位置的卡背。负荷与合法性仍由内核检查。地图房间与通道只改变表现，原节点行动、返回位置和探索路线继续生效。

自然浏览器测试使用原科学牌组，并通过普通鼠标和键盘操作完成对局。没有注入资源、改写结果或跳过内核。最终测试的三个结果分别为玩家与怪物点数 `0:4`、`20:21`、`15:71`。这是表现与交互验收，不是自动玩家策略的胜率评估。

整局验证发现了一处表现错误：同一格位中的卡牌实例键与效果帧键偶尔撞号。已给两种键分别添加 `card:` 与 `effect:` 前缀。真实步骤与中间动画帧的卡牌实例没有重复。修复后重新完成三个怪物的整局验证。

原音频路径在当前仓库中没有对应资源，已改用本地 Web Audio 合成的低频氛围与短音效。音乐和音效设置继续独立保存。
