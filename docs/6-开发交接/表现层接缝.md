# 表现层接缝

第一轮冻结。第二轮只许给事件**新增可选字段**，不许改名、删字段、改判定。`npm run sim -- --compare` 同种子必须与 `src/tools/baseline.json` 逐位一致。

表现层只做三件事：`dispatch(命令)`、`ask(查询)`、按序 `await` 每条事件做演出。读模型是终态快照，不能用来播动画。演出期间锁输入，只留 `Space` 快进。

默认像素表现。白模：`?present=dom`（保留一个版本周期）。控制台 `called.game`。

类型：只从 `src/application` 引 `GameCommand`、`GameQuery`、`BattleView`、`RunView`。

---

## 命令

| type | 载荷 | 何时合法 |
| :-- | :-- | :-- |
| `run.start` | `{ seed? }` | 随时。开一趟，残响 10 张进卡盒和牌组，血 30 |
| `run.abandon` | | 有进行中的一趟 |
| `run.enterNode` | `{ node: 'yuZhuang' \| 'drawer' \| 'boShou' \| 'shouMen' }` | 地图上，且是当前可进节点。不能跳 |
| `run.setDeck` | `{ deck: string[] }` | 仅地图。至少 1 张，张数不超过卡盒里同 ID |
| `run.eventOption` | `{ index: 0\|1\|2 }` | 事件屏，还没选 |
| `run.rewardPick` | `{ cardId }` | 奖励屏，且在本次 `pool` 里 |
| `run.finishFlow` | | 战斗已 `settled`；或事件已选；或奖励已选 |
| `battle.play` | `{ card; cell?: 1-9; target? }` | 出牌阶段。法术不传格；需要指定时加 `target` |
| `battle.endTurn` | | 化身已入场，出牌阶段 |

`card` / `target` 是实例 ID（`c1`…）。`deck` / `cardId` / 卡盒是定义 ID（`P01`…）。

## 事件

每条带 `text` 日志行。`seq` / `stream` 由 EventStore 盖。

### 战斗

| type | 字段 | 建议演出 |
| :-- | :-- | :-- |
| `battle.started` | `encounterId`, `setup[]` | 摆敌阵 |
| `battle.avatarDealt` | `card`, `defId`, `deckLeft` | 化身入手 |
| `battle.cardDrawn` | `card`, `defId`, `deckLeft` | 抽牌飞入手牌 |
| `battle.turnStarted` | `turn`, `opening`, `leading`, `won` | `won` 为真则本场结束。开战 `opening: true` 不检查领先 |
| `battle.phaseChanged` | `phase: play \| pressure \| over` | 压迫阶段整桌微震 |
| `battle.manaChanged` | `current`, `cap` | 费用水晶涨格 |
| `battle.cardPlayed` | `card`, `defId`, `kind`, `cell?` | 出手 |
| `battle.cardCovered` | `victim`, `by`, `cell`, `victimPoints` | 压扁被盖者，弹出 `-N` |
| `battle.cardEntered` | `card`, `cell`, `covered` | 占场落地；覆盖则从手牌飞入该格 |
| `battle.cardRemoved` | `card`, `defId`, `cell`, `to`, `reason` | `cover \| effect \| banish`；化身碎裂 |
| `battle.pointsChanged` | `card`, `before`, `after`, `source` | 飘字 |
| `battle.statusAdded` / `statusRemoved` | `card`, `status: 'sealed'` | 锁链 |
| `battle.pressureResolved` | `cell`, `defId`, `kind` | 按格号前倾/砸桌 |
| `battle.leadChanged` | `leading` | 领先边光 |
| `battle.settled` | `outcome`, `reason`, `wound` | `reason: lead \| avatarGone \| noPlay`。伤口数字 |

## 视图

`BattleView` 可直接绑 UI，不必再算规则：

- 格 1–9：`card?`、是否角落、阴影地是否生效
- 每张实例：owner、zone、cell、基础/当前点、封印、是否化身
- 手牌、牌组剩余、弃牌数（敌方离场不进弃牌堆）
- 费用 current/cap、双方最终点数、是否领先、回合、阶段
- 化身：在场？当前点？预估伤口 `max(0, 10 - 当前点)`
- `mustPlaceAvatar`、`canEndTurn`、`result?`

`RunView`：血、卡盒、牌组、当前节点、可进节点、屏幕、种子、事件选项、奖励池。

## 场景路由

跟 `run.screen` / `run.battleQueued` / `battle.started`：

| screen | 场景 |
| :-- | :-- |
| （未开局） | Title |
| `map` | Map + 卡盒编组 |
| `event` | Event 三选一，选完 `finishFlow` |
| `reward` | 奖励三选一，选完 `finishFlow` |
| `battle` | Battle。`settled` 后 `finishFlow` |
| `over` | Ending |

节点顺序：余桩 → 裂开的抽屉 → 剥手 → 守门。

## 关键时序

玩家回合开始：**领先检查 → 封印解除 → 费用回满 → 抽 1**。开战回合跳过这四步，且不能结束回合直到化身入场。压迫按格 1→9，封印跳过。化身离场立刻判负。

## 禁止

- 用读模型补间或反推「刚才发生了什么」
- 在 present / pixel 里改点数、费用、胜负
- 改事件名、删字段、改判定
- 敌方出牌 AI、格子填满比大小、卡牌移动换位
- 第一轮没有的体系：精神负荷、卡背、信仰、遗物、三层地图
