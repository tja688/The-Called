# 事件与奖励

## 事件 · 裂开的抽屉

余桩之后、剥手之前，必经。三选一，选完往前走。

| 选项 | 结果 |
| :-- | :-- |
| 摸出一块冷铁 | 卡盒加入「冷钉子」（占场，0 费，6 点，无效果） |
| 包扎 | 血条 +8，不超过上限 |
| 夹层 | 下一场战斗开战多抽 1 张（化身 + 5）。只对剥手生效一次 |

冷钉子不进初始表，只从这里来。6 点 0 费，能盖阴影地后变成 5 的角，是给不想喝药的人的。

## 战斗奖励

余桩、剥手胜利后各做一次三选一。从下表抽 3 张不同的给玩家看，选 1 张进卡盒。

余桩的池子偏节奏，剥手的池子偏保命和破阵。同一趟里已经拿到的 ID 不再出现。

### 余桩池

从这里抽 3 张：`R01 倒刺` `R02 重锤` `R03 抽薪` `R06 清场`

### 剥手池

从这里抽 3 张：`R04 旧锁` `R05 回声` `R07 锚` `R08 点名`

池子只有 4 张，抽 3 看 1。每场会留下 1 张没看见。两场打完，玩家卡盒里是 10 张初始 + 2 张奖励 + 可能的冷钉子。

守门不发牌。

## 编组

奖励进卡盒，不自动进牌组。牌组无上限，加新牌不用先砍旧牌。也可以故意不带某张，避免把关键牌稀释掉。
