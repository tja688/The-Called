# 遭遇

三场。敌方占场开局就在格子上。表里的「基础」是卡面点数。场上实际当前点数还要加阴影地和驻场。

格子：

| 1 | 2 | 3 |
| :---: | :---: | :---: |
| 4 | 5 | 6 |
| 7 | 8 | 9 |

## 战斗1 · 余桩

教学。敌方不追化身，只罚站在中圈的人。

开局：

| 余桩 4 |  |  |
| :---: | :---: | :---: |
|  | 重心 7 |  |
|  |  | 余桩 4 |

阴影地后两张余桩变成 5。开局最终点数 5+7+5 = **17**。

| ID | 名称 | 格 | 基础 | 驻场 | 压迫 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| E1A | 余桩 | 1 | 4 | — | — |
| E1B | 重心 | 5 | 7 | — | 相邻的玩家占场各 -1。斜向不算，化身在角落通常挨不到。 |
| E1A | 余桩 | 9 | 4 | — | — |

玩家该学会：化身落角落拿阴影地；不要第一下用化身去盖重心（10 盖 7，化身剩 3，血会疼）；用余温削重心，或用镇纸盖余桩。

## 战斗2 · 剥手

开始猎化身。站位第一次变成对错题。

开局：

| 盯人 5 |  | 余桩 4 |
| :---: | :---: | :---: |
|  |  |  |
|  | 剥手 6 |  |

阴影地后盯人 6、余桩 5。开局最终点数 6+5+6 = **17**。

| ID | 名称 | 格 | 基础 | 驻场 | 压迫 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| E2A | 盯人 | 1 | 5 | — | 若化身与本卡相邻，且化身当前点数 ≤ 5，**驱离**化身。 |
| E1A | 余桩 | 3 | 4 | — | — |
| E2B | 剥手 | 8 | 6 | — | 点数最低的一张非化身己方占场 -2。若因此当前点数变为 0，将该牌移除。 |

盯人在格1，相邻是格2、格4。化身落格7或格9都挨不到它。落格2、格4是送。

剥手逼玩家要么继续铺小占场喂它，要么少铺、改用法术削点。回声放在它嘴边是故意的：被剥死能给化身 +2。

## 战斗3 · 守门

按 BOSS 处理。化身离场则整趟失败。

开局：

| 门柱 3 | 横梁 5 | 门柱 3 |
| :---: | :---: | :---: |
|  | 守门人 7 |  |
|  |  |  |

横梁驻场让上排各 +1。阴影地再给两个门柱 +1。场上实际：门柱 5、横梁 5、门柱 5、守门人 7。开局最终点数 **22**。

| ID | 名称 | 格 | 基础 | 驻场 | 压迫 |
| :-- | :-- | :-- | :-- | :-- | :-- |
| E3A | 门柱 | 1 | 3 | — | — |
| E3B | 横梁 | 2 | 5 | 上排其他敌方占场各 +1 | — |
| E3A | 门柱 | 3 | 3 | — | — |
| E3C | 守门人 | 5 | 7 | — | 化身 -1。若结算前化身当前点数 ≤ 3，改为**驱离**。 |

守门人在中心，和所有边格相邻，和四个角不相邻。化身继续躲角是对的，但 -1 每回合都会打到化身，不看相邻。

先拆横梁，上排会掉下来。封口或点名可以关掉守门人一轮压迫，用来把领先撑过检查点。清场能收掉被削残的门柱。锚能把化身钉在 4，避免被驱离，但守门人每回合仍在抠血。

## 敌方牌离场

被覆盖或被清场移除后，驻场立刻失效，之后不再压迫。不进玩家弃牌堆。
