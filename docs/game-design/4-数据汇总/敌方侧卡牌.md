## 拓展敌方侧卡牌

按施压维度分为三类，每张卡只做一件事，压迫感由[[怪物数据]]中的组合与摆放位置产生。卡面中的「敌方」指玩家侧（见 [[卡牌]] 指代约定）。

**地形税**（让某些格位变差，考验落位）：EC.06、EC.07、EC.10、EC.19、EC.23  
**资源攻击**（打手牌、牌组、驻场效果，考验构筑）：EC.11、EC.16、EC.17、EC.21、EC.22

| 卡牌名称 | 卡牌效果1 | 卡牌效果2 | 点数 |

| EC.06 | **EC.06.FX1**：**驻场**本卡所在横排上的敌方卡牌点数-2（实时计算） | 无 | 18 |
| EC.07 | **EC.07.FX1**：**驻场**本卡所在竖列上的敌方卡牌点数-2（实时计算） | **EC.07.FX2**：回合结束时，随机向左或向右沿排格**移动**一格（目标格位被占据时不移动） | 20 |

### 结算备注

- EC.17 可以封印化身卡；被封印的化身卡在该回合开始的总点数检查中计 0。
- EC.19 的限制只针对「打出到空格位」；玩家仍可用点数更大的占场卡覆盖 EC.19 本身或其相邻格位上的敌方卡牌。EC.19 离场时对化身卡点数-2。
- EC.11 洗入的 PC.X01 属于战斗内获得的卡牌，存放在[[牌组]]，战斗结束随牌组复原消失，不进入[[卡盒]]。
