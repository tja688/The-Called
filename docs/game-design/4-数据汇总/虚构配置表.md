# 虚构配置表

规则文档只写 Key。玩家可见的名称、情境与旁白以本表为准。

机制仍以各规则文档为准，本表不改规则。玩家看见的叫法用地下城里常见的词：英雄、印记、法力、精英、Boss、商店、宝箱、休息处、铁匠铺。

视觉、空间与每个对象怎么画见 [`Playtest虚构设计总纲.md`](../Playtest虚构设计总纲.md)。

键名前缀：`SYS` 体系、`PC` 玩家侧卡牌、`EC` 敌方侧卡牌、`MON` 怪物、`RL` 遗物、`ME` 地图效果、`EV` 事件、`DK` 初始牌组、`MK` 标记、`RES` 资源。

编号约定：

- `PC`：体系字母 + 两位序号。`00` 为该体系化身卡，其后按该体系在 [[玩家侧卡牌]] 中的顺序；`N` 为中立。
- `MON`：`N` 普通 / `E` 精英 / `B` BOSS，后接序号。
- `EV` 选项：`A` / `B` / `C` 对应选项1 / 2 / 3；`.TXT` 为情境。选项后的 `.TXT` 是结算句，按钮上的规则句仍以事件配表为准。
- `FX` 为卡牌自身效果名（不属于 [[词条]]），只给设计对照，不显示给玩家。
