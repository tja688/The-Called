# 虚构设计总纲（playtest）

这份文件管「看起来像什么」。规则仍以 `docs/game-design/` 为准。玩家可见名称、效果名、事件旁白以 [`docs/game-design/4-数据汇总/虚构配置表.md`](docs/game-design/4-数据汇总/虚构配置表.md) 为准，两边名称必须一致。

这是一层普通地下城。英雄进去打怪物，打赢 Boss 离开。不接旧 demo 的钉子 / 灯芯 / 余桩 / 守门人。机制词（占场、化身、覆盖、卡盒、占领费用、化身代价）留在规则配表里，不在这里改名。

玩家看见的字用常见说法：游侠、死灵法师、牧师、印记、法力、精英、Boss、商店、宝箱、休息处、铁匠铺。印记画成金漆，法力画成灯油。

本局只跑设计案第 1 层。第 2、3 层的名字在配置表里占好了位，本文只给外形一句，不铺空间。

画画时：像素、`MASTER` 色板、整数像素，见 `.cursor/skills/pixel-layer/SKILL.md`。每个对象下面的色名都是 `src/pixel/palette.ts` 的键。

**本层要画** = 这一层会出现、要优先出图。  
**未建层** = 第 2 / 3 层才出场，外形先定，场景不建。

## 一句话

你是进地下城的英雄。这一层有食人魔、骷髅、蜘蛛和史莱姆，大厅尽头是瘟疫之心和两台巨石。游侠、死灵法师或牧师，打赢 Boss 就能离开。

## 故事（短）

地下城是石砖挖出来的。门生锈了，里面还亮着几盏灯。

三种英雄：

- **游侠**给怪物挂上印记。猎犬、箭和网都认这个标记。
- **死灵法师**把牌组当燃料，弃牌堆当分数。
- **牧师**攒法力。灯产出法力，盾和祝福花法力。

目标：打倒这一层的 Boss **瘟疫之心**，带上金币和牌离开。playtest 到此为止。

## 地下城：空间

九宫格战场是一间石室的地面，3×3 块地砖。砖缝长苔。四边有锈铁栅和墙根。没有天光。壁灯只剩半截，火焰 `lamp1` / `lamp2`，烟往上贴 `ink2`。

大地图是同一层里折来折去的走廊网，不是世界地图。玩家从 **入口**（地图中心）起步。正交相邻才能看见节点类型。

### 氛围

湿、锈、窄、有东西在隔壁动。不是宇宙恐怖，也不是光明圣殿。气味（文案用，不入画）：铁锈、湿毛、灯油。声音：骨节走路、水滴、远处有人拖东西。

光：点光源。壁灯、圣灯、法力的金光、印记的金漆。死灵侧用骨灰白 `cream` 和 `purpleD`，不要霓虹。

### 本层天气（地图效果，顶栏常驻）

每局地下城只抽一个，双方都吃。这是建筑在干活，不是魔法天气。

- **ME.01 狭窄**：走廊太窄，挨着自己人会互相撑住（邻格己方各 +1）。画：肩甲相抵、砖缝被踩亮。
- **ME.02 血地**：刚夺过位的地砖又湿又滑，覆盖者会打滑（覆盖者 -1）。画：砖面一层暗红，脚印发亮。
- **ME.03 掩体**：背靠墙根比较稳（角落格 +1）。画：四角堆沙袋和旧盾，苔更厚。

## 地下城：生物群落

一层里住着几窝，不要画成动物园大杂烩。同场出现的东西要能解释为什么在同一间房。

**旧盔甲的骷髅。** 骷髅兵（EC.07）在巡廊右列走班，压一整列，还会沿排横移。他们不吃、不睡。大厅里站着瘟疫之心和两台巨石。

**门厅巨物。** 食人魔（EC.01）独居门厅，闻见人就挤过来砸，相邻 -3。大厅门神是瘟疫之心（EC.04）：计时给全场玩家 -1，左右两台巨石（EC.05）沿竖列压过去。

**洞穴节肢。** 蛛后（EC.02）在产房后墙产卵；卵（EC.03）破了会溅伤旁边的人、喂旁边的巢。

**凝胶。** 史莱姆（EC.19）趴在边厅，三团堵住格 1、格 2、格 9。挨着它们的空格不准直接放牌，覆盖它们会咬化身。点数只有 2。

**环境物。** 酸液（EC.06）垂在巡廊上排，税一整排。血苔（EC.10）占苔室中心，贴它就涨。

**鼠与商店。** 老鼠（EC.11）蹲在苔室两角，回合结束往牌组里塞诅咒。商店老板玩家只叫他商人。外形是戴油布兜帽的地城商贩，尖牙、铜秤。不进战斗。

**蛀牌。** 蛀虫（EC.16）在边厅两角啃手牌。占场卡被啃到 0 就进弃牌堆，化身再掉 2 点。

食物链（画画时的关系，不是规则）：蛛后吃老鼠；食人魔吃一切活的；骷髅不吃；史莱姆吃湿气和血地上的残留；瘟疫之心不吃，它只让别人变弱。

## 三系冒险者

化身是九宫格上的「你」。三张化身卡都是一个人，站立，脚底锚点。体型接近：肩宽不超过一格的 2/3。不要巨兽化身。

### SYS.A 游侠 / PC.A00 游侠

皮甲、短披风、短弓或手弩斜背。腰上挂一小罐 **印记** 金漆（`sta` / `gold`）。眼睛和漆一样亮一点。发色深、脸脏。印记落在敌人身上时是一块不规则的金漆，不是魔法阵。

主动触发（给带印记的敌卡易伤）：举起漆罐往那只猎物上弹一指金漆。

主色：`brown` `pack` `leaf` `gold`。不要板甲，不要精灵尖耳。

### SYS.B 死灵法师 / PC.B00 死灵法师

灰袍、骨杖、领口一圈肋骨饰。脸是活人，但扑了骨灰（`cream` 扑在 `gray1` 上）。手指黑。献祭时是把牌（小骨片 / 纸符）扔进杖头的碗里烧掉。

主动触发（抽两张）：杖碗一震，两片骨符飞入手牌。

主色：`gray1` `purpleD` `cream` `ink`。不要骷髅头头骨当头；这是活人术士。

### SYS.C 牧师 / PC.C00 牧师

锈白法衣，前襟油渍。铜香炉或油壶（`copper` / `gold`）。法力画成粘稠金液，像灯油，不是光柱。保护和复活都从这滴油来。

主动触发（全场己方 +1）：把一滴灯油弹到场上，每张己方卡的灯火跳一下。

主色：`cream` `paper` `dai` `gold` `copper`。不要全白圣骑士，不要翅膀。

### 中立

谁都能用的地城杂货：盾、锤、地图、砖、符、钥匙、鼓。木和铁，`wood1` `stone` `copper`。不要体系色满铺。

## 对象图鉴

画之前先读对应 Key 的规则（点数、占场/法术、效果）。图要让人看出这张卡在干什么，不要只写名字。

体量：化身 ≈ 人；占场物 ≈ 能放进一格的道具或小生物；法术 ≈ 图标（手、箭、油滴、符）。精英/BOSS 的主体可以撑满一格，瘟疫之心和巨石锚点仍在格心。只画虚构配置表里还在的 Key。

### 游侠 PC.A

**PC.A00 游侠**（化身 / 本层要画）  
见「三系冒险者」。站姿：弓在背，一手随时能去腰上的漆罐。

**PC.A01 猎犬**（占场 / 基础 / 本层要画）  
肩高到游侠膝的短毛犬。项圈挂小漆罐，鼻尖金漆。回合结束给邻格敌人点印：爪子也沾漆。`brown` `pack` `sta`。不要狼，不要盔甲犬。

**PC.A02 猎箭**（法术 / 基础 / 本层要画）  
一支短箭，箭头缠金漆布。没印就普通射；有印则把布扯下来多伤一次。图标：箭 + 一滴金漆。

**PC.A03 猎网**（占场 / 基础 / 本层要画）  
钉在地上的绳网，网结上有倒刺。驻场绞带印记的猎物。`wood2` `gray2` `gold`。

**PC.A04 标记**（占场 / 白 / 本层要画）  
入场时漆从这格溅到所有邻格敌人。画一只打翻的漆罐，金漆呈放射状。

**PC.A05 转印**（法术 / 白 / 已移出本轮，不画）  
一只戴皮手套的手把金漆从这只猎物刮到旁边那只。箭头要看见「印在挪」。

**PC.A06 猎杀**（法术 / 蓝 / 已移出本轮，不画）  
割喉短刃，刃上金漆。只收点得动的小猎物（点数 ≤ 6 且有印）。血腥要克制：一道红线即可。

**PC.A07 围猎**（占场 / 蓝 / 已移出本轮，不画）  
一面小鼓，鼓皮画着围猎圈。场上猎物越多，鼓越响、这张卡越胖。希望猎物活着。不要画成已经打死的战利品堆。

**PC.A08 短剑**（占场 / 白 / 本层要画）  
贴身短剑。旁边有带印的敌人才亮。刃短、护手有漆斑。点数低、贴脸，画成冒险者跨进邻格的那一刺。

**PC.A09 陷阱**（占场 / 金 / 本层要画）  
地面掀开的钉板，钉子从砖缝长出来。带印的敌人被钉住不能移动，每回合被钉子咬一口。`copper` `stone` `gold`。

**PC.A10 包抄**（法术 / 蓝 / 已移出本轮，不画）  
俯视：几只己方的小影子围住一只带印猎物。伤看你有几个邻居。

**PC.A11 齐射**（法术 / 金 / 已移出本轮，不画）  
一排箭同时离弦，每支箭尖金漆。射完印消失。气势可以满，但不要阳光。

**PC.A12 毒矢**（占场 / 白 / 已移出本轮，不画）  
箭头一截绿，一截金。入场给邻格上印并易伤。绿用 `leaf` / `sprout`，不要毒液喷泉。

**PC.A13 对位**（占场 / 蓝 / 本层要画）  
一张拉满的弓对着镜像格。计时 2：弦上有两道刻痕。射的是「对面那格」不是「面前」。背景可画碎镜一角。

**PC.A14 瞄准**（法术 / 蓝 / 本层要画）  
漆刷。给一张敌卡刷上印记，同时抽一张牌。

### 死灵 PC.B

**PC.B00 死灵法师**（化身 / 本层要画）  
见「三系冒险者」。

**PC.B01 双尸**（占场 / 基础 / 本层要画）  
两具用红线缝在一起的小尸，一张卡代表「这一对」。打出后一对会分到镜像格。一个走了另一个也拆线倒下。`cream` `gray1` `redD`。不要两张脸笑。

**PC.B02 指骨**（占场 / 基础 / 本层要画）  
一颗埋进砖缝的指骨。入场和离场都会再长一颗进牌组。画：骨芽刚顶开苔藓。

**PC.B03 食尸**（法术 / 基础 / 本层要画）  
一张嘴对着弃牌堆在嚼。弃牌越多，选中的那张卡越肥。图标：下颌骨 + 碎骨。

**PC.B04 骨火**（占场 / 白 / 本层要画）  
入场烧掉牌组里两张当柴，自己涨一圈火。小骨堆上有 `lamp2` 火苗。火是祭火，不要圣光。

**PC.B05 回收**（法术 / 白 / 本层要画）  
一只从弃牌堆里往外刨的手（灰袖，同死灵法师）。

**PC.B06 吞并**（占场 / 白 / 本层要画）  
一张能叠到自己人身上的嘴。吃掉那张己方非化身卡，把点数吞进来。画：骨盔张开，里面是空的。

**PC.B07 亡鼓**（占场 / 蓝 / 本层要画）  
蒙人皮的鼓（克制：鼓皮是灰白的，不要写实皮肤）。己方每走一张，敲一声，这张卡 +2。

**PC.B08 焚谱**（法术 / 白 / 已移出本轮，不画）  
一页牌名录在烧。献祭 3 抽 1。纸灰 `gray2`，火芯 `lamp2`。

**PC.B09 开坟**（占场 / 金 / 已移出本轮，不画）  
打出后本局烧掉自己（燃尽）。入场把弃牌堆整堆掀回牌组。画：砖面裂开，骨头倒流回去。体积可以大。

**PC.B10 碎骨**（占场 / 白 / 本层要画）  
一把松散的指骨。离场时弹一张牌到手。轻、碎、便宜。

**PC.B11 复制**（法术 / 蓝 / 本层要画）  
选一张己方非化身卡，在空格生成一张它的复制。影子边缘用 `fog` / `purpleL`。

**PC.B12 尸堆**（占场 / 蓝 / 本层要画）  
一小坟。弃牌堆里占场越多坟越高。离场把自己洗回牌组：坟塌回去。

**PC.B13 血宴**（法术 / 金 / 已移出本轮，不画）  
碗。献祭 4 张，把它们的基础点数倒进一张己方卡。碗沿血用 `redD`，不要喷溅满屏。

**PC.B14 棺材**（占场 / 蓝 / 本层要画）  
一口很浅的棺。牌组将尽（≤5）时它给你牌并自己涨；否则往牌组里再埋一具自己。棺盖半开。

### 牧师 PC.C

**PC.C00 牧师**（化身 / 本层要画）  
见「三系冒险者」。

**PC.C01 圣灯**（占场 / 基础 / 本层要画）  
铜座壁灯，每回合结束产出 1 点法力。火芯 `lamp1`，座 `copper`。灯油就是牧师的法力。

**PC.C02 圣盾**（法术 / 基础 / 本层要画）  
圆盾正面一滩油光。花 1 点法力给保护。盾是地下城里捡的旧盾，牧师涂了油。

**PC.C03 充能**（占场 / 基础 / 本层要画）  
一只加油壶伸向灯。回合开始花 1 油，这张卡 +2。壶口要看见金液。

**PC.C10 余油**（占场 / 白 / 已移出本轮，不画）

**PC.C13 复活**（法术 / 金 / 本层要画）

**PC.C14 守夜**（占场 / 白 / 本层要画）

### 事件 EV

事件是一间具体的小房间加 2～3 个按钮。情境画背景；选项名写在按钮上；旁白是结算句，不必另画。地下城池见 [`docs/game-design/2-系统机制/事件.md`](docs/game-design/2-系统机制/事件.md) 的出现层数。

**本层要画**

**EV.01 半开的箱子**  
箱室。铁箱微开，硬币反光 + 一截扎手木柄（可能是战锤那种）。选项：只拿金币 / 连东西一起抽出。连东西一起抽出掉 5 血。

**EV.02 水井**  
同休息处那口井，但水面有金光在跳。井壁刻字要能看见「可以喝。别贪。」选项：喝水 / 捞闪光。

**EV.03 遇难的冒险者**  
一个人影卡在砖缝里，破布，还活着，不要画成骷髅兵。他伸出手，掌心一张卡。选项：拉他出来 / 拿走那张牌 / 绕开。

**EV.04 整理行囊**  
一段干砖。玩家蹲着摊牌。选项：丢掉诅咒 / 抄一张 / 背上就走。

**EV.05 染血的武器**  
武器架。一件金边兵器结着血痂，旁边一把普通的。拿金的得金卡，拿旁边的得蓝卡。

**EV.06 商店**  
倒扣的盾当柜台。商人：矮、尖牙、油布兜帽、铜秤。收牌、改牌。

**EV.09 两个匣子**  
左右两只匣，左贴职业标记（游侠漆罐 / 死灵下颌 / 牧师圣灯，随开局职业换），右贴杂货印。左匣蓝卡，右匣中立卡。

**EV.10 诅咒祭坛**  
长绿毛的石坛。坛下几只老鼠抬头。有诅咒才会出现。第三项是再拿一张诅咒换金币。

**EV.11 赌瓮**  
封口陶瓮，旁边写着「30 金币，一半金卡，一半白卡」。不要老虎机。

**EV.13 过路税**  
过廊木牌：行囊薄有赏，行囊沉也有赏。

**EV.15 小摊**  
折叠摊，货少。买旧货会垫一张诅咒。

**EV.16 侧门**  
门缝里有打斗声和钱袋声。推门就是一场本层普通战斗。

## 色与禁

用现成 `MASTER`，不要为这套虚构换色板。

| 用途 | 键 |
|-|-|
| 石、砖、骨 | `stone` `stoneL` `tile1` `slate` `cream` |
| 锈、铜、旧铁 | `copper` `copperD` `gray1` |
| 苔、霉、卵汁 | `leaf` `sprout` `teal` |
| 灯、引信、祭火 | `lamp1` `lamp2` `lamp3` |
| 印记、法力、金币 | `sta` `gold` `goldL` |
| 血、嗜斗 | `redD` `fruR` |
| 死灵灰、镜 | `gray1` `purpleD` `fog` |
| 木、皮、行囊 | `wood1` `brown` `pack` |

**要画成：** 传统地城。闸门、地砖、锈戟、蜘蛛、史莱姆、食人魔、巨石、商贩老鼠。

**不要画成：** 旧 demo 的桌灯客厅、钉子楔子镇纸、守门人横梁；不要科幻；不要全息魔法阵；不要把占领费用画成法力水晶。

印记永远是金漆。法力永远画成金液。骷髅兵是穿着旧盔甲的骷髅，不是万圣节骨架。瘟疫之心是一颗还在跳的黑心，不要画成龙。

## 地下城出图顺序

先景，再人，再本层会打到的东西：

1. 入口 / 巡廊 / 大厅三张背景
2. 三张化身（游侠、死灵法师、牧师）
3. 三套基础占场与法术（猎犬猎箭猎网、双尸指骨食尸、圣灯圣盾充能）+ 碎砖

5. 节点：商店商人、渗泉、铁砧、锈箱
6. 本层事件背景（半开的箱子、水井、死冒险者优先）
7. 其余拓展卡、遗物战锤、狭廊/血砖/墙根图标
8. 未建层对象可以留 `?` 占位
