# 定义

将某个大量使用的前缀效果进行具体命名，以减少卡面描述的字量。卡面上词条以**加粗**显示，悬停可查看解释。卡牌自身的效果名同样以加粗显示，但不属于词条，不提供悬停解释。卡牌效果名见 [[虚构配置表]]。

# 时机词条

| 名称 | 效果 |
|-|-|
| **入场** | 当卡牌被打出到战场时触发一次（被效果「生成」到战场的卡牌同样触发入场；被「移动」的卡牌不触发） |
| **驻场** | 当本卡在[[九宫格战场]]上且未被封印时持续生效；本卡离场或被封印时立即失效 |
| **离场** | 当本卡从战场被移除时触发（被覆盖、被效果移除均算） |

# 空间词条

| 名称 | 效果 |
|-|-|
| **相邻** | 正交相邻格上。格位术语见 [[九宫格战场]]。 |
| **角落格** | 格1、格3、格7、格9 |
| **镜像** | 两张卡牌处于镜像格上时（格1↔格9、格2↔格8、格3↔格7、格4↔格6） |
| **镜像格** | 本卡所在格的镜像格 |

# 格位词条

| 名称 | 效果 |
|-|-|
| **覆盖** | 两个不同归属的卡牌争夺同一格位时触发：打出到对方卡牌所在的格位（打出时必须自己的点数更大），或效果明确允许的移动进入对方卡牌所在的格位。点数大的一方占据该格位并扣除点数小的一方的点数，点数小的一方移入[[弃牌堆]]；若两张卡点数相同，则两张卡都移入弃牌堆，该格位变为空格位 |
| **移动** | 移动到正交相邻的空格位，目标格位被占据时无法移动；方向未指定时：目标为斜向，则在构成该斜向的两个正交相邻格位中随机选择一个落脚；沿竖列移动，则随机向上或向下一格，若已在列顶或列底则固定向内侧一格 |

# 卡牌状态词条

| 名称 | 效果 |
|-|-|
| **封印** | 卡牌不提供点数，效果（入场后的驻场效果）不生效；回合开始时移除封印 |
| **返魂** | 当卡牌被移除时（含被覆盖），移除返魂状态，使卡牌回到[[手牌]]中（手牌满则进入弃牌堆） |
| **易伤** | 拥有本状态的卡牌，点数减少时额外减少25%（向上取整），回合结束时移除 |
| **保护** | 拥有本状态的卡牌，点数减少时，阻止这次点数减少并移除本状态 |

# 资源与代价词条

| 名称 | 效果 |
|-|-|
| **RES.A** | SYS.C 体系资源，战斗内积累，战斗结束清零。「消耗 X RES.A」：RES.A 不足时效果不生效，卡牌仍正常入场。名称见 [[虚构配置表]]，体系内用法见 [[玩家侧卡牌]]。 |
| **献祭 X** | 随机将[[牌组]]内 X 张卡牌移入弃牌堆（X 见卡面）。牌组不足 X 张时，卡牌可以打出但效果不生效。强度参照见 [[数值锚点]]。 |
| **燃尽** | 打出后本局永久移除：该卡从[[卡盒]]中一并移除，不会随战斗结束的牌组复原回到牌组或弃牌堆 |
| **主动触发** | 玩家点击卡牌后产生对应效果，仅会生效一次 |
| **计时X** | 回合开始时，X-1，当X归零后，触发卡牌效果，并将X重置为初始值 |
