# 地图效果

## 定义

地图产生的全局效果，每个战斗[[地图节点]]都生效。**每层开始时从本层池中随机抽取 1 个**，在大地图顶部常驻显示，本层所有战斗（普通、精英、BOSS）都受其影响。所有地图效果默认双方生效。名称见 [[虚构配置表]]。对点数构成的影响见 [[点数]]。

## 效果总表

| 地图名称 | 效果 | 出现层数 |
|-|-|-|
| ME.01 | 九宫格战场上每张卡牌，每有一张相邻的己方卡牌，点数 +1（实时计算） | 1 |
| ME.02 | 每当一张卡牌覆盖另一张卡牌，覆盖者点数 -1 | 1 |
| ME.03 | 角落格上的卡牌点数 +1 | 1 |
| ME.04 | 中心格上的卡牌点数 -2 | 2 |
| ME.05 | 卡牌打出时，若其镜像格上有己方卡牌，该卡牌点数 +2 | 2 |
| ME.06 | 排格上同时存在 3 张己方卡牌时，该排所有己方卡牌点数 +3（实时计算） | 2 |
| ME.07 | 上下左右均无相邻卡牌的卡牌点数 +3（实时计算） | 3 |
| ME.08 | 斜交相邻格上有敌方卡牌的卡牌点数 -2（实时计算） | 3 |
| ME.09 | 每当一张卡牌被覆盖而移入弃牌堆，与其相邻的己方卡牌点数 -1 | 3 |
