# 层级循环

## 大地图总节点数

每层[[地图节点]]生成总数为18个（1个商店地图节点，1个BOSS战斗地图节点，1个精英战斗地图节点，1个宝箱地图节点，1个疗养地地图节点，1个锻造地地图节点，7个事件地图节点，5个普通战斗地图节点）

## 总层数

一局游戏共 3 层，在第 3 层互动下层地图节点即游戏通关。

## 起点

大地图的中心

## 具体层级循环

| 生成顺序 | 具体实现 |
|-|-|
| 1.**每层开始** | 玩家生成在起点 |
| 2.**生成地图节点** | 在起点的正交相邻格中生成 3-4 个地图节点（至少有 2 个普通战斗节点，其余从事件地图节点中随机挑选）；再从每个已生成的地图节点出发，在其正交相邻格中生成 1-3 个地图节点；每个格位最多容纳 1 个地图节点；重复上述生成直到地图节点数量达到 18 个（BOSS战斗地图节点生成在离玩家最远的位置，若有两个及以上可挑选的位置则随机生成在其中一个位置） |
| 3.**玩家大地图交互** | 玩家只能与正交相邻地图节点互动，只能看到正交相邻地图节点的类型。玩家与地图节点互动完后将移动到该地图节点所在位置，也可自由返回已互动完毕的地图节点。移动到未互动的地图节点会强制触发其互动 |
| 4.**进入下层** | 当玩家在BOSS战斗地图节点胜利后，在BOSS正交相邻格生成下层地图节点，玩家可自行选择时机互动，互动后进入下一层（若为最后一层则游戏通关） |

局内循环总览见 [[循环]]。
