# 定义

玩家在大地图上可选择触发的基础单位，不同节点按照所属类型产生不一样的作用，玩家只能看到正交相邻格上地图节点的具体类型，除商店（未来可能有其他的）与战败的普通/精英战斗地图节点外，其余地图节点互动结束后不可再次互动。生成规则见 [[层级循环]]。战斗内流程见 [[战斗节点流程]]。

# 具体节点类型

| 节点类型 | 作用 |
|-|-|
| 普通战斗 | 从普通级怪物中随机选择一种与玩家进行战斗，胜利后从三张随机[[玩家侧卡牌]]中挑选一张获得，并获得小额金币。怪物见 [[怪物数据]]。 |
| 精英战斗 | 从精英级怪物中随机选择一种与玩家进行战斗，胜利后从三张随机玩家侧卡牌中挑选一张获得，并获得中额金币和一件[[遗物]] |
| Boss战斗 | 从BOSS级怪物中随机选择一种与玩家进行战斗，胜利后获得大额奖励 |
| 随机事件 | 从所有事件中随机选择一个进行，详见[[事件]] |
| 商店 | 可消耗金币使用商店服务，详见[[经济]] |
| 宝箱 | 从三个随机遗物中挑选一个获得 |
| 疗养地 | 互动后选择一项：回复[[血条]]上限 30% 的血量（向上取整）；或[[化身卡]]基础点数 +2、血条上限 +2（本局内持续） |
| 锻造地 | 互动后选择一项：使[[卡盒]]中一张卡牌的基础点数 +2（可反复强化同一张卡）；或将卡盒中一张卡牌重铸为同稀有度的随机另一张卡牌 |
| 下层 | 选择后进入下一层（若为最后一层则游戏通关） |
