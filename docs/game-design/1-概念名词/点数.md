# 点数

## 定义

用于决定大小的数值。增减来源中的地图效果见 [[地图效果]]。

| 名称 | 定义 |
|-|-|
| 基础点数 | 卡牌的初始值 |
| 当前点数 | 卡牌经过增减的实际数值，下限为 0 |
| 总点数 | 一方所有战场卡牌的当前点数之和 |

## 当前点数的构成

```
当前点数 = max(0, 基础点数 + 永久增减 + 驻场增减 + 地图效果增减 )
```

| 来源 | 说明 | 何时失效 |
|-|-|-|
| 永久增减 | 入场效果、敌方效果、覆盖造成的 +X / -X | 卡牌离场前一直有效；施加者离场也不撤销 |
| 驻场增减 | 「驻场」类卡牌提供的光环 | 施加者离场或被封印时立即撤销 |
| 地图效果增减（状态型） | 条件满足期间生效的[[地图效果]]，如 ME.01、ME.03 | 条件不满足时撤销（实时重算） |
| 地图效果增减（事件型） | 每次触发即结算的地图效果，如 ME.02、ME.09 | 触发后永久计入，不随条件变化重算 |

## 哪些数值参与比较

| 场景 | 使用的数值 |
|-|-|
| 覆盖判定 | 争夺双方各自的当前点数 |
| 效果条件（如「点数 ≤ 2 的敌方卡牌」） | 目标的当前点数 |
| 封印中的卡牌 | 总点数计 0，但覆盖判定仍使用其当前点数 |
