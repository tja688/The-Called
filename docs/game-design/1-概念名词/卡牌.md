<title>卡牌</title>

# 定义

游戏中战斗所需的基础单位，不同卡牌根据自身具体设计产生不同效果。

# 卡牌存放

游戏内，玩家通过[[地图节点]]获得的卡牌，将记录并存放在\*\*[[卡盒]]**里，每局游戏结束后清空。  
战斗节点内，通过战斗中获得的卡牌（复制、生成），将存放在**[[牌组]]**里；战斗胜利奖励属于地图节点获得的卡牌，存放在**卡盒\*\*。战斗结束后牌组将复原到初始状态。

# 卡牌与格位的关系

- 一个格位同时只容纳一张卡牌。
- 卡牌一旦入场即属于打出它的一方，只会被特殊效果转移归属。
- 卡牌离开战场时，其对其他卡牌造成的**永久增减仍然保留**，其**驻场效果立即失效**

# 指代约定

卡面效果中的「己方」指该卡牌的所属方，「敌方」指另一方。

# 稀有度

卡牌稀有度分为 基础、白、蓝、金 四档。稀有度为**基础**的卡牌不会出现在任何卡牌选择池中。

# 卡牌类型

## 占场卡

本身拥有点数，打出后会留在[[九宫格战场]]上的卡牌

## 法术卡

本身没有点数，打出后触发完效果直接进入[[弃牌堆]]的卡牌

## 化身卡

独立于占场卡的一种卡牌类型，功能与占场卡一致（本身拥有点数、打出后留在九宫格战场、打出规则与驻场规则均沿用占场卡），差异仅在于：打出到九宫格战场时，额外立刻提供 1 点可用的占领费用。类型细则见 [[化身卡]]、[[费用]]。

# 额外类型

负面卡是附加在卡牌类型之上的**额外类型**，可与占场卡、法术卡、化身卡任意共存（例如一张卡同时是"占场卡 + 负面卡"）。

带有负面卡标记的卡牌**无法通过编辑牌组从牌组中移除**。
