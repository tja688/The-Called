# 战斗节点流程

战斗节点流程固定为以下阶段，前一阶段未完成不得进入下一阶段：

| 顺序 | 规则层描述 |
|-|-|
| 1.**战斗节点开始** | 战斗节点开始，记录当前[[牌组]]初始状态 |
| 2.**怪物生成** | 确定本战斗节点出场怪物，按照[[怪物数据]]摆放[[敌方侧卡牌]] |
| 3.**回合循环** | 按照[[回合流程]]一直循环直到满足[[胜利与失败条件]] |
| 4.**战后结算** | 将牌组复原到初始状态，扣除终局[[化身卡]]点数与初始化身卡点数差值的血量（差值下限为 0） |
| 5.**奖励环节** | 在上一流程中玩家胜利后，根据所处战斗节点类型获得对应奖励，详见[[地图节点]] |
| 6. **战后去向** | 胜利后回到大地图，自行选择下一节点；战败则不获得奖励，直接回到大地图 |
