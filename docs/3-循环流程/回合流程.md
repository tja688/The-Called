# 回合流程

回合为双方共用，流程固定为以下阶段，前一阶段未完成不得进入下一阶段。本流程由 [[战斗节点流程]] 进入。

| 顺序 | 规则层描述 |
|-|-|
| 1.**回合开始** | 所有[[费用 |
| 2.**玩家抽牌** | 从[[牌组]]抽 1 张卡牌作为[[手牌]]。手牌达到上限时不抽取，牌组为空时不抽取 |
| 3.**玩家行动** | 玩家可选择打出手牌到[[九宫格战场]]，直到玩家主动结束回合。 |
| 4.**回合结束** | 触发所有回合结束时的效果（玩家侧先于敌方侧结算） |

回合流程会一直循环，直到满足[[胜利与失败条件]]

同一阶段内同一阵营的多张卡同时触发效果时，按格位编号从小到大（格1 → 格9）依次结算。
