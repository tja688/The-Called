# 单回合流程

## 开战回合

战斗布置结束后进入。不检查领先，不回费用，不抽牌。

1. 玩家必须打出化身。打出前不能打其他牌，不能结束回合。
2. 化身入场，获得 1 点可用费用。
3. 出牌阶段：可以打费用够的牌，可以主动结束。
4. 压迫阶段。
5. 进入之后的玩家回合。

## 之后的玩家回合

1. **领先检查**。己方最终点数 > 敌方最终点数则胜利，本回合结束。
2. 封印到期解除。
3. 当前费用回满到上限。
4. 抽 1。牌组空或手牌满则按 [[手牌]] 处理。
5. 出牌阶段。
6. 若出牌阶段开始时没有任何合法打出，且未领先，本场失败。
7. 玩家结束回合后进入压迫阶段。
8. 压迫结束后回到步骤 1。

## 出牌阶段里的一张牌

1. 检查费用、目标、覆盖条件。
2. 扣费用。
3. 占场：入场或覆盖；法术：结算后进弃牌堆。
4. 触发入场。
5. 实时重算点数、驻场、地图效果、费用上限。

一张牌结算完才能打下一张。
