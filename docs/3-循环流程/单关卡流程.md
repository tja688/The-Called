# 单关卡流程

一场战斗。

## 开始

1. 按遭遇表布置敌方占场。
2. 套上本层地图效果。
3. 生成化身进手牌，从牌组抽 4。
4. 费用 0 / 0。
5. 进入开战回合。

## 进行

按 [[单回合流程]] 循环，直到胜利或失败。

## 胜利结算

1. 按 [[血条]] 扣除化身掉点。
2. 若血条归零，整趟失败。
3. 否则：余桩、剥手进入三选一奖励，见 [[事件与奖励]]。守门不发牌，直接通关。
4. 牌组、弃牌堆、场上、手牌、化身全部清掉，牌组复原。
5. 回到地图。

## 失败结算

1. 余桩 / 剥手：扣 10 血。血条归零则整趟失败。否则回地图，该节点仍可进入。
2. 守门：整趟失败。
3. 牌组同样复原。卡盒不退还已经拿到的奖励。
