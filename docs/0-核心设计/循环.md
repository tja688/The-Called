# 循环

本原型只有一趟试玩、一层地图。

```
选初始牌组（本原型只提供一套「残响」）
  → 进入地图
  → 战斗1 余桩
  → 事件 裂开的抽屉
  → 战斗2 剥手
  → 战斗3 守门
  → 通关
```

地图上可以随时打开卡盒改牌组，张数无上限。战斗和事件进行中不能编辑。

## 结束

| 结果 | 条件 |
| :-- | :-- |
| 通关 | 赢下守门 |
| 失败 | 血条归零；或守门中化身被移除 |

普通和精英战败不结束整趟，扣血后回到地图，该节点仍可进入。详见 [[血条]]、[[领先与胜负]]。

## 战斗之间留下什么

| 留下 | 不留下 |
| :-- | :-- |
| 血条 | 牌组在战斗里的复制、生成、弃牌 |
| 卡盒里的牌 | 化身（每场重发） |
| 牌组编成 | 费用、领先状态、场上牌 |

更细的节点顺序见 [[单层流程]]。
