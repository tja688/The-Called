# 游戏概述

《The Called》第四版战斗原型。桌上是双方共用的九宫格。敌方开局就占着几格，带着高点数和压迫效果。玩家把化身放进去，用占场扩费用、用法术削点，把己方点数压过对方，再撑过一轮压迫。

本原型只做 **一层、三场战斗、一个事件**。用来回答四件事：

1. 化身必须先落地，会不会让开局有决策，而不是走过场。
2. 「领先还要再撑一回合」够不够当胜负核。
3. 怪物不打牌、只压迫，压迫够不够恨。
4. 化身掉点扣血，会不会让人护化身，而不是把化身当普通占场。

## 做

- 九宫格、占场、覆盖、费用水晶、化身、领先检查、压迫、血条、无上限牌组、卡盒编辑
- 三场遭遇，难度递进
- 一场事件、两场战斗奖励
- 一层固定地图效果：阴影地

## 不做

- 敌方出牌、敌方手牌、敌方 AI 选牌
- 格子填满再比大小
- 精神负荷、卡背、信仰、献祭、三大体系
- 遗物、商店、三层大地图
- 卡牌移动 / 换位（草图已标成危险设计）
- 锁定世界观和完整文案
