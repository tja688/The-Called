# 网页表现改为二维俯视像素场景

2026-10-12，用户要求以 [Achroma](https://game.unsnow.online/ach/) 的画面效果重做网页表现层，取消三维与二维混合视角。此决定替换 ADR-0012 中关于三维场景的表述，规则内核、内容目录和宿主边界继续遵循 ADR-0012。

## 决定

场景使用低分辨率 Canvas 2D，按最近邻方式放大。背景由灰阶地砖、像素接缝、裂纹、Bayer 抖动和少量漂浮颗粒组成。卡面与角色使用自行绘制的像素 SVG。文字和交互控件使用 DOM，以保留中文清晰度、焦点和辅助技术支持。

主菜单、遗迹地图、卡盒与构筑、对局共用暖白、近黑、红、青、金和紫的色板。红与青区分怪物和玩家，卡面学派用青、紫、金表示。落牌、点数变化和离场通过入场位移、短时闪白、像素碎屑与浮动点数表现。

`PcdBattle` 直接显示内核的 `PcdView`。`beatsFor` 将现有事件与视图分成表现节拍，`cellChoice` 只把内核选项映射为格位点击。手牌与战场始终同时显示，取消镜头状态切换。点击、拖动、法术施放和能力选择全部提交现有 `PcdOption.id`。

## 取舍

Canvas 全屏绘制全部 UI 会让中文文字、键盘焦点和规则说明难以维护，因此保留清晰的 DOM 界面。继续沿用三维相机无法满足固定二维俯视要求，因此当前入口不再引用 Three.js 或 React Three Fiber。

参考作品的可公开访问源码用于确认色板、分辨率和动画机制。项目不导入参考作品的代码或美术文件。这里使用的符号、像素卡面、场景与合成音效由本项目代码生成。

## 验证

`node scripts/check-2d.mjs` 检查当前入口可到达的模块不包含三维渲染依赖。`scripts/verify-2d.js` 从真实界面完成三个怪物的对局，核对合法格位、提交的选项与结果点数，记录控制台错误并保存桌面和手机截图。

本次验收使用本地 `Pcd.DevHost`。浏览器 WebAssembly 的发布与验证仍沿用原工作流。
