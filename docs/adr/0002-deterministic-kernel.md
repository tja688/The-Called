# 内核严格确定性

相同的内容版本、内核版本、对局配置、随机种子与完整决策序列，必须在任何一端产生逐字节相同的对局过程与结果。为此内核只用整数表示规则数值；只用内核自带、状态可序列化的伪随机数生成器；不依赖字典遍历顺序、系统时钟与运行环境；不允许可变的静态状态；录像记录全部决策，包括怪物 AI 当时的选择。换来的是任意 bug 可由录像复现，回放、悔棋、批量模拟与双端一致性校验几乎零成本。

## Consequences

- 约束只作用于内核。表现层的动画、音效与视觉效果可以自由使用浮点数、时间与随机数，只要结果不回流进规则。
- 任何需要"思考时间"的决策者（例如搜索型 AI）必须以迭代次数或节点数计量预算，不能以毫秒计量。
- 规则改动会让旧录像失效，录像必须绑定内核版本与内容版本。
- Unity 6.6 新项目默认不做域重载，静态变量会跨次运行残留；"禁止可变静态状态"同时避开了这个坑。
