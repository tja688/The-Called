# 开战先结算回合开始，化身赶不上这一次

每回合固定先走回合开始（解封、计时、回合开始效果、总点数检查、占领费用回满、抽 1），再让玩家行动。开战时化身还在手牌，场上没有化身，所以第一次回合开始只作用在已摆好的敌卡上（L1 BOSS 的 EC.18 会先 -5）。开战跳过抽牌和胜利检查；占领费用从 0 起，化身入场再立刻 +1。化身赶上当回合的回合结束，赶不上当回合的回合开始。

**Considered Options**: 第一次回合开始推迟到玩家结束第 1 回合之后（化身已在场，EC.18 晚一拍）；开战跳过整段回合开始。

**Consequences**: 敌方「回合开始」在玩家落化身前就会跳。计时从开战那一次就开始减。
