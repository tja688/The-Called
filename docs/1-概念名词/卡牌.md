# 卡牌

战斗里打出的基本单位。

## 存放

| 来源 | 去哪 |
| :-- | :-- |
| 地图节点得到的牌（奖励、事件） | [[卡盒]]。一趟结束清空 |
| 战斗里复制、生成的牌 | 本场 [[牌组]] / 手牌 / 弃牌堆。战斗结束复原 |
| 化身 | 战斗内生成，结束销毁 |

## 与格位

- 一格同时只放一张牌。
- 入场即属于打出它的一方。本原型没有改归属的效果。
- 离场时：对其他牌造成的永久增减保留；自己的驻场立刻失效；所在格的锁定解除（本原型无锁定）。

## 占场卡

本身有点数。打出规则：

1. 目标格为空，直接入场。
2. 目标格是对方占场，且打出牌的当前点数大于目标当前点数，则覆盖，见 [[覆盖]]。
3. 不能打到己方占场上。
4. 不能覆盖化身。

费用写在卡面上。0 费占场不花水晶，入场后增加费用上限。

## 法术卡

没有点数。不占格。打出后立刻结算，进入弃牌堆。目标与费用写在卡面上。
