# 化身卡

玩家在这一场必须放进九宫格的那张占场。战斗内生成，不算牌组，不进卡盒。

## 生成

- 每场战斗开始时生成 1 张，放进手牌。
- 基础点数 10。当前点数按 [[点数]] 计算，阴影地等地图效果入场后照常加。
- 战斗结束销毁。下一场重新生成一张 10 点的。

## 打出

- 化身未入场时，玩家不能打出其他牌，也不能结束回合。
- 可以打到空格。
- 可以覆盖当前点数更小的敌方占场，覆盖算法与普通占场相同，见 [[覆盖]]。
- 入场后立刻提供 1 点可用费用，见 [[卡牌费用]]。

## 目标限制

化身是特殊占场。效果若只写「指定一张占场 / 一张卡牌」，不能选化身。效果必须写明「化身」才能选它。覆盖也不能选化身。

压迫效果可以写明化身。玩家卡里，本原型只有「撑住」「灯芯」（相邻加成）「旧锁」「锚」「回声」会碰到化身。

## 离场

化身被覆盖（本原型敌方不打牌，不会发生）、被效果移除、被驱离，都算出离场。

| 战斗 | 后果 |
| :-- | :-- |
| 余桩、剥手 | 血条扣除初始化身点数（10）。回到地图，节点仍在，可再打 |
| 守门 | 整趟失败 |

## 战后扣血

化身还在场上时：

```
扣血 = max(0, 初始化身点数 - 终局当前点数)
```

涨过初始点数不回血。化身离场视为终局当前点数 0，因此扣 10，与上表一致。

血条归零则整趟失败，即使这一场已经打赢。
