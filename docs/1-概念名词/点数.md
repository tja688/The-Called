# 点数

用来比大小的数。

| 名称 | 定义 |
| :-- | :-- |
| 基础点数 | 卡面印着的初始值 |
| 当前点数 | 这张牌现在用来覆盖和加总的值，下限 0 |
| 最终点数 | 一方所有未封印战场占场的当前点数之和，再加上效果提供的额外点数 |

## 当前点数

```
当前点数 = max(0, 基础点数 + 永久增减 + 驻场增减 + 地图效果增减)
```

| 来源 | 说明 | 何时失效 |
| :-- | :-- | :-- |
| 永久增减 | 入场、法术、压迫造成的 +X / -X | 这张牌离场前一直有效；施加者离场也不撤 |
| 驻场增减 | 「驻场」光环 | 施加者离场或被封印时立刻撤 |
| 地图效果增减 | 如阴影地 | 条件不满足时撤，实时重算 |

## 哪一个数拿来比

| 场景 | 用哪个 |
| :-- | :-- |
| 覆盖判定 | 手牌里那张牌的当前点数（地图效果还没上身）> 目标的当前点数 |
| 效果条件（点数 ≤ 3 的敌方） | 目标的当前点数 |
| 领先与胜负 | 最终点数 |
| 封印中的牌 | 最终点数计 0；覆盖判定仍用它的当前点数；压迫不结算 |

手牌里的占场没有永久增减和地图效果，当前点数通常等于基础点数。
